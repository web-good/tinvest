# pdl_reclaim — возврат над вчерашним лоем на 5m

Бэктест-стратегия, только лонг, внутридневная. Прогон **только на 5m** (`-interval Minutes5`, другие cmd/backtest отклоняет): до 10:00 сигналы читаются на 5m свечах, с 10:00 — на получасовых, собранных из них. Уровни — лой (PDL) и хай (PDH) вчерашнего буднего дня: PDL — поддержка, у которой ищется вход, PDH — цель. Позиция через ночь не переносится: держится до последней свечи вечерней сессии (23:45). Код: `internal/service/trading_strategy/pdl_reclaim/strategy/core`, привязка к бэктесту — `internal/service/backtest/pdl_reclaim_registry.go`. Спека: `docs/superpowers/specs/2026-10-15-pdl-reclaim-design.md`.

## Уровни

- **PDL / PDH** — low и high последней завершённой будней дневки (выходные дневки отброшены; в понедельник это пятница). Дневка биржевая — со всеми сессиями дня.
- **Дневной ATR** — Уайлдер `DailyATRPeriod` по завершённым будним дневкам; уходит в сигнал и замораживается на позицию.
- Нет дневок для уровней или ATR — входов нет.

## Таймфрейм

- До `SwitchHour:SwitchMinute` (10:00) сигнальная свеча — 5m: последняя 09:55, покупка не позже 10:00.
- С 10:00 сигнальная свеча — получас, собранный ядром из 5m по границам :00/:30 МСК. Ряд получасов непрерывный через дни, на нём прогреваются RSI и MACD. Получас закрыт на своей 5m свече :25/:55, а если её нет в данных — на первой свече более позднего получаса; формирующийся получас в расчёт не идёт. Первый сигнальный получас — 10:00–10:30 (покупка в 10:30); для входа B предыдущий — 09:30–10:00.
- Покупка всегда по open следующей 5m свечи.
- Позиция живёт на таймфрейме входа: исполнение раньше `Switch + 30m` — 5m позиция, её RSI- и MACD-выходы читают 5m и после 10:00; иначе — 30m позиция, RSI и MACD читаются на закрытии получаса. Стоп, цель и конец дня проверяются на каждой 5m свече у любой позиции.
- `SwitchHour = 24` — весь день на 5m.
- Таймфреймы включаются по отдельности, у каждого тикера свои значения в литерале пакета. `Entry5m = 0` выключает входы по 5m-сигналу, то есть утро до Switch, а при `SwitchHour = 24` весь день. `Entry30m = 0` выключает входы по получасам: после Switch тикер не входит, сигналы на 5m после 10:00 тоже не читаются. Флаги гасят только входы, выходы открытой позиции работают как прежде.

## Вход

Вход — формация на сигнальной свече (5m или получасе) без открытой позиции. Формации делятся по месту:

- **у уровня** — формация пересекла PDL или PDH вверх: самый низкий low её свечей ниже уровня, close последней свечи выше. RSI-фильтра нет;
- **вне уровней** — разворот где угодно ещё; он нужен только при низком RSI (ниже).

**Формации** (при совпадении нескольких побеждает C, затем A, затем B):

- **A — ложный пробой PDL** (`EntryA = 1`): свеча зелёная, low < PDL, close > PDL. Всегда у уровня.
- **C — пробой PDH** (`EntryC = 1`, по умолчанию выключен): свеча зелёная, close > PDH, предыдущая свеча того же таймфрейма и той же даты закрылась не выше PDH — первое закрытие над вчерашним хаем. Всегда у уровня.
- **B — бычье поглощение** (`EntryB = 1`): предыдущая свеча той же даты красная; текущая зелёная, её close выше open красной, её low ниже low красной. Где угодно: у уровня, если пара свечей пересекла PDL или PDH вверх, иначе вне уровней.

**Только уровни** (`LevelsOnly = 1`, по умолчанию выключен): входы только у вчерашних уровней. У PDL — отскок формацией разворота, пересёкшей лой вверх (A, поглощение, будущие паттерны). У PDH — только пробой вверх C; поглощение, которое лишь проверило хай сверху (красная закрылась над PDH), не входит. Развороты вне уровней выключены.

**Допуск до уровня** (`LevelTolATR > 0`): формация разворота «дошла» до уровня, если самый низкий low её свечей ниже уровня плюс `LevelTolATR ×` дневной ATR; close последней свечи всё равно выше уровня. Так отскок чуть выше PDL без касания считается отскоком от уровня. A и C от допуска не меняются: прокол PDL и закрытие над PDH заданы строго.

Новые формации разворота добавляются кейсом в `pattern()` и сразу получают это деление и RSI-фильтр.

**RSI-фильтр разворота вне уровней** читает свечу перед разворотом (у поглощения — красную):

- на 5m: RSI(`RSIPeriod`) по close 5m строго ниже `RSIEntryMax` (50); свечей для RSI не хватает — входа нет;
- на получасах — часовой: RSI(`HourRSIPeriod`) по close часов строго ниже `HourRSIMax` (30). Часы ядро собирает из 5m по границам :00 МСК, ряд непрерывный через дни. Последний час собирается только из 5m-свечей до закрытия получаса перед разворотом, так что поглощение 10:30–11:00 читает час 10:00 по свечам 10:00–10:25. Часов не больше `HourRSIPeriod` — входа нет. Если `HourRSIPeriod` или `HourRSIMax` равен 0, на получасах действует `RSIEntryMax` по RSI получаса.

Общие условия:

- будни МСК, сигнальная свеча начинается не раньше `EntryFromHour:EntryFromMinute` (07:00);
- свеча покупки (следующая 5m) начинается раньше `EntryToHour:EntryToMinute` (18:00) в ту же дату — последний сигнальный получас 17:00–17:30;
- close сигнала выше PDH — пробой: вход только при `EntryC = 1`, цели нет; иначе при включённой цели close ниже цели;
- стоп `close − StopDailyATR · ATR` выше нуля.

Фильтры, выключены по умолчанию:

- **Гэп** (`GapOnly = 1`): вход только в день, чья первая 5m свеча открылась ниже PDL; окно без начала дня — входа нет.
- **Подтверждение** (`Confirm = 1`): формация читается на предыдущей свече того же таймфрейма и той же даты, а сигнальная свеча обязана закрыться выше пересечённого уровня, у разворота вне уровней — выше close свечи паттерна. RSI-фильтр — по свече перед разворотом, стоп и проверка цели — от close подтверждающей. Свеча паттерна тоже не раньше `EntryFrom` (на 30m — не раньше Switch). Паттерн 5m на 09:55 не подтверждается: свеча 10:00 уже на получасах.
- **Цель — середина диапазона** (`TargetMid = 1`): цель `(PDL + PDH) / 2` вместо PDH; close сигнала не ниже цели — входа нет.
- **Сила свечи** (`BodyATR > 0`): у свечи паттерна тело `close − open` строго больше `BodyATR ×` дневной ATR, а у формации у уровня ещё и отрыв close от пересечённого уровня. ATR тот же, что идёт в стоп. У поглощения проверяется зелёная свеча. При `Confirm` проверяется свеча паттерна.
- **Объём пробоя** (`VolumeMult > 0`): объём свечи паттерна должен быть строго больше `VolumeMult ×` среднего объёма свечей того же таймфрейма, начавшихся в то же время МСК, за `VolDays` прошлых будних дат. Для 5m свеча 07:05 сравнивается со свечами 07:05, для получаса 10:30 — с получасами 10:30. Объём получаса равен сумме его 5m свечей. Свеча паттерна для A и C — сама свеча, для B — зелёная поглощающая, при `Confirm` — свеча перед подтверждающей. День, где в этот слот не было свечи, пропускается, поиск идёт дальше в прошлое. Сессии выходного дня в среднее не входят. Если в окне меньше `VolDays` дат или у свечей нет объёмов, входа нет. Вместе с `GapOnly = 1` фильтр работает только в гэп-дни.

Покупка по open следующей 5m свечи (`Config.EntryAtNextOpen`, `FillBy` = время текущей 5m свечи + 5m). Сигнал несёт стоп (для `-risk-pct`), цель и ATR; `Level` — пересечённый уровень, у разворота вне уровней PDL. После выхода перевход в тот же день разрешён.

**Позиция пробоя.** Купленная выше PDH при `EntryC = 1` позиция выходит по SL, MACD и EOD, RSI-выход у неё выключен, иначе RSI(6) после пробоя продавал бы её на следующей свече. Позиция ниже PDH, исполненная выше него гэпом, сразу закрывается по цели; при `TakeProfitPDH = 0` она тоже теряет RSI-выход.

## Выход

По приоритету на каждой 5m свече (RSI и MACD — на таймфрейме позиции):

1. **SL** — `low ≤ вход − StopDailyATR · ATR` (стоп от цены исполнения, ATR замороженный). Исполнение `min(стоп, open)`.
2. **TP** — у A/B `high ≥ цели` (PDH или середина диапазона, заморожена на входе). Исполнение `max(цель, open)`. Стоп и цель в одной свече — стоп.
3. **RSI** — RSI(`RSIPeriod`) по close таймфрейма позиции ≥ `RSIExit` (не у позиции пробоя). Продажа по close текущей 5m свечи.
4. **MACD** — гистограмма MACD(`MACDFast`, `MACDSlow`, `MACDSignal`) по close таймфрейма позиции была зелёной (`≥ 0`) хотя бы на одной свече от свечи входа (для 30m — получаса, в котором исполнен вход) до предыдущей, а на текущей красная. Продажа по close. Зелёная уже на свече входа — считается.
5. **EOD** — первая свеча, начавшаяся не раньше `ExitHour:ExitMinute` (23:45 — последняя 5m свеча вечерней сессии), продаётся по close; первая свеча новой даты или свеча даты позже входа — тоже.

RSI в `pkg/indicators` на отрезке без единого падения даёт 50, а не 100: на ровном росте RSI-выход не сработает, пока не будет хоть одного отката.

## Параметры

| поле | по умолчанию | смысл |
|---|---|---|
| `EntryA` | 1 | вход A; 0 — выключен |
| `EntryB` | 1 | поглощение B (где угодно); 0 — выключено |
| `StopDailyATR` | 0.5 | стоп ниже входа в дневных ATR; 0 — входов нет |
| `DailyATRPeriod` | 14 | длина дневного ATR Уайлдера по будням |
| `TakeProfitPDH` | 1 | цель PDH; 0 — без цели |
| `RSIPeriod` | 6 | длина RSI — общая для фильтра входа и выхода, на таймфрейме сигнала/позиции; 0 — оба выключены |
| `RSIEntryMax` | 50 | разворот вне уровней только при RSI свечи перед ним строго ниже этого (на получасах — при выключенном часовом гейте); 0 — фильтр выключен |
| `RSIExit` | 70 | уровень RSI-выхода; 0 — выключен |
| `MACDFast` / `MACDSlow` / `MACDSignal` | 9 / 26 / 8 | MACD выхода на таймфрейме позиции; некорректные периоды — выключен |
| `EntryFromHour` / `EntryFromMinute` | 7 / 0 | сигнальная свеча не раньше |
| `EntryToHour` / `EntryToMinute` | 18 / 0 | свеча покупки раньше |
| `ExitHour` / `ExitMinute` | 23 / 45 | выход в конце дня (последняя свеча вечерней сессии) |
| `SwitchHour` / `SwitchMinute` | 10 / 0 | с этого времени сигналы на получасах; 24 — весь день 5m |
| `GapOnly` | 0 | 1 — входы только в день с открытием ниже PDL |
| `Confirm` | 0 | 1 — покупка после свечи, закрывшейся выше PDL вслед за паттерном |
| `TargetMid` | 0 | 1 — цель середина вчерашнего диапазона вместо PDH |
| `Entry5m` | 1 | входы по 5m-сигналу (утро до Switch); 0 — выключены |
| `Entry30m` | 1 | входы по получасам с Switch; 0 — после Switch входов нет |
| `VolumeMult` | 0 | объём свечи паттерна выше этого × среднее слота; 0 — фильтр выключен |
| `VolDays` | 20 | число прошлых будних дат в среднем слота |
| `HourRSIPeriod` | 6 | длина часового RSI для разворотов вне уровней на получасах |
| `HourRSIMax` | 30 | часовой RSI на получасах строго ниже этого; 0 — на получасах `RSIEntryMax` |
| `EntryC` | 0 | 1 — вход C на первом закрытии над PDH и любые входы с close выше PDH, без цели |
| `LevelsOnly` | 0 | 1 — только отскок от PDL и пробой PDH (C); развороты вне уровней не входят |
| `LevelTolATR` | 0 | low формации разворота в пределах этого × дневной ATR над уровнем считается касанием; 0 — нужен прокол |
| `BodyATR` | 0 | тело свечи паттерна (у формации у уровня и отрыв от него) больше этого × дневной ATR; 0 — фильтр выключен |

`Lookback = W · max(64, 3 · (MACDSlow + MACDSignal), 4 · RSIPeriod + 2) + 202` 5m свечей, где `W` = 6 при включённом переключении (прогрев на получасах) и 1 без него; 202 — свечи от 07:00 до 23:45. При дефолтах 814. С фильтром объёма первое слагаемое не меньше `(VolDays · 7/5 + 3) · 202`: окно дотягивается до `VolDays` будних дат с запасом на сессии выходного дня. При `VolDays = 20` получается 6464 свечи, и прогон заметно медленнее.

## Пакеты тикеров

Реестр `pdlReclaimRegistry` держит по одному литералу `Params()` на откалиброванный тикер (`internal/service/trading_strategy/pdl_reclaim/strategy/<ticker>/`); тикер без пакета работает на `core.DefaultParams()`; JSON `-params` / `-calibrate` ложится поверх. Стартовая сетка — `data/params/pdl_reclaim/grid_example.json`.

## Вселенная для live

Живого раннера нет; вселенная под него — `PDL_RECLAIM_TICKERS_M5` (`config.PDLReclaimConfig`). Тест `TestPDLReclaimLiveTickersAreRegistered` требует пакет в `pdlReclaimRegistry` у каждого тикера из `env/prod.env`.

## Запуск

```bash
go run ./cmd/backtest -strategy pdl_reclaim -interval Minutes5 -ticker GAZP -months 12
go run ./cmd/backtest -strategy pdl_reclaim -interval Minutes5 -ticker GAZP -months 12 \
  -calibrate data/params/pdl_reclaim/grid_example.json -metric profit_factor
# почему на свече был (или не был) вход/выход
go run ./cmd/backtest -strategy pdl_reclaim -interval Minutes5 -ticker GAZP -months 12 -explain "2026-09-03 10:00"
```
Окно бэктеста и калибровки — 12 месяцев (`-months 12`); три года не нужны. Для калибровочных прогонов — собранный бинарь на одном ядре.
