# IRKT под `rsi_pullback` — план подготовки, калибровки и вердикта

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести IRKT (ПАО «Яковлев») до вердикта по стратегии `rsi_pullback`: каталог максимально
широких сеток, канонический тематический walk-forward, принятая точка, прошедшая два риск-гейта и
**шесть** пунктов стоп-условия на **трёх** схемах проверки, при провале — второй круг, и либо
литерал в пакете с заведением в боевую вселенную тридцатым тикером, либо протокол отказа.

**Architecture:** Процедура каноническая, но исходная позиция уникальна тем, что **каноническое
окно лжёт**. Получасовая история уходит на год глубже канонического окна, и схема 48/12/6 даёт
шесть фолдов вместо четырёх: дефолты ядра дают pooled OOS **1.795** на 36/12/6 при четырёх
прибыльных фолдах из четырёх и **1.010** на 48/12/6 (0.877 под кругом 0.2%), потому что каноническое
окно начинается сразу после двух худших полугодий бумаги и не проверяет их ни разу. Весь in-sample
рельеф канонического окна задан **одной свечкой** — печатью 2024-02-03 в выходную сессию, стоившей
−27 178.65 ₽ (−29.46% капитала) одной сделкой, — и механизм этой потери живой, а не модельный.
Отсюда три отличия от каталога: тематические walk-forward идут по канонической схеме (иначе темы
несопоставимы), но **точка проверяется по трём схемам**; стоп-условие получает **шестой пункт**
(pooled OOS ≥ 1.2 на 48/12/6 при круге 0.2%) и **пятый** (круг 0.3%, потому что модель издержек
оптимистична вдвое); риск-гейт B переведён на однородное 24-месячное окно, потому что просадка
baseline на каноническом окне на 73% состоит из одной сделки. Одиннадцать тем поверх дефолтов ядра;
тема `trend_volume` **не заводится** — объёмный гейт на IRKT инертен или вреден.

**Tech Stack:** Go 1.25, `cmd/backtest` (rolling walk-forward), `cmd/pullparity` (сверка живой
сборки с бэктестом), `./bin/mage ci` (lint + `go test -race ./...` + дрейф моков), `python3` для
разбора журналов сделок.

**Spec:** `docs/superpowers/specs/2026-09-11-irkt-rsi-pullback-prep-design.md`
**Замеры:** `reports/_analysis/irkt_pullback_prep_measurements.md`

  превосходстве pooled OOS над первичной `day`.

  что уже на 1.0 стоп срабатывает три раза на 98 сделок, а на 1.5 — ноль). **Порог после прогонов
  не двигается.**
- **РИСК-ГЕЙТ B (в изменённой форме, объявлено до прогонов):** max DD точки **на однородном

  отделяет только гейт A.
- **ПРАВИЛО НИЧЬИХ:** при разнице pooled OOS < 0.05 в точку идёт вариант с меньшей просадкой **на
  24-месячном окне**.
- **Третий контур:** опорные числа дефолтов на трёх окнах (48 / 36 / 24 мес) — доля SL
  **27.0% / 21.9% / 18.4%**, удержание медиана/p90/максимум **8/21/46, 10/24/46, 9/22/46**, ночёвок
  **51.7% / 46.9% / 42.9%**, выходов в выходную сессию **8.4% / 11.7% / 11.2%**, входов в выходную
  сессию **0 / 0 / 0**, max DD **47.78% / 36.66% / 6.83%**, expectancy
  **+22.42 / −25.05 / +486.77 ₽**.
- **ОБЯЗАТЕЛЬНЫЙ ПЕР-ТИКЕРНЫЙ ЗАМЕР — экспозиция в выходную сессию.** Для принятой точки три числа:
  (а) входов в выходные бары, (б) выходов в выходные бары, (в) **позиций, перенесённых через
  выходные** (вход в пятницу или раньше, выход в понедельник или позже). Число (в) записывается в
  доку пакета **всегда**, независимо от направления изменения.
- **Планка:** `entry` и `trend` (канонические, **не** `trend_hump`) обе дают pooled OOS PF ≥ 1.5 при
  ≥ 20 сделках; ведущая ось (`RSILower` для `entry`, `EMASlow` для `trend`) выбрана одинаково в ≥ 3
  фолдах из 4; вырожденный фолд в пользу тикера не засчитывается. **Ожидание, записанное заранее:
  планка НЕ будет взята** — обе темы меряются на каноническом окне, где ось входа даёт провал ровно
  на дефолте, а вся ось `EMASlow` лежит под 1.1.
- **СТОП-УСЛОВИЕ ПЕРВОГО КРУГА ИЗ ШЕСТИ ПУНКТОВ.** Точка не проходит, если:
  1. pooled OOS PF < 1.0 на **36/12/6**;
  2. < 20 сделок в пуле OOS канонической схемы;
  3. pooled OOS PF < 1.0 на **24/12/3**;
  4. pooled OOS PF < 1.0 на 36/12/6 при `-commission 0.001` (круг 0.2%);
  5. pooled OOS PF < 1.0 на 36/12/6 при `-commission 0.0015` (круг 0.3%) — **введён потому, что
     модель издержек на IRKT ОПТИМИСТИЧНА**: шаг 0.02 ₽ при цене 19.40 ₽ даёт круг **0.206%**
     против 0.1% модели, и падение цены делает его хуже (на минимуме окна 11.66 ₽ — 0.343%).
     Прецедент RTKMP;

     единственный нестандартный пункт. Порог 1.2, а не 1.0, и под кругом 0.2%, а не 0.1%: дефолты
     дают на этой схеме 1.010 при 0.1% и **0.877** при 0.2%, то есть порог 1.0 при 0.1% точка взяла
     бы, ничего не доказав. Схема — единственная, проверяющая два худших полугодия вне обучающего
     окна.
- **КРИТЕРИЙ КАЛЕНДАРНЫХ ЛЕТ:** не более **одного** убыточного календарного года **на 48-месячном
  окне**; убыточный год с менее чем **десятью** сделками непредставителен и не считается (снимает
