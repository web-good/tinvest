## Step 3 — вердикт арбитража (§5.2 спеки)

Три pooled OOS рядом:

| Тема | pooled OOS PF | пул |
|---|---|---|
| **`trend_volume`** (эта тема) | **2.243** | 50 |
| `trend_hump` (Task 5) | 1.382 | 63 |
| `volume` (Task 7) | 1.195 | 59 |

Разрывы:

- `trend_volume` − `trend_hump` = 2.243 − 1.382 = **+0.861 PF**.
- `trend_volume` − `volume` = 2.243 − 1.195 = **+1.048 PF**.

**Оба разрыва материальны, не шум.** Единственный установленный на SFIN шумовой порог — разница
между `trend` и `trend_hump` (0.002 PF, Task 5, «одна сделка на границе фолда способна её
перекрыть»). Разрывы этой темы (0.861 и 1.048) больше того порога **более чем в 400 и 500 раз** —
они не приближаются к зоне, где решение можно спутать со случайностью.

**Тема выше обеих сравниваемых — рычаги СКЛАДЫВАЮТСЯ.** По правилу Step 3 брифа: «если тема выше
обеих — рычаги складываются, и оба поля идут в точку по своим темам». Следствие для задачи 11:
поля тренда (`EMAFast`, `EMASlow`) берутся из решения темы `trend_hump` (Task 5), поля объёмного
гейта (`UseVolume` и форма гейта) — из решения тем `screen`/`volume`/`vol_window` (Task 3, Task 7);
эта тема не переопределяет их и не урезает точку до одного рычага. Собственные голоса
`trend_volume` по трём осям (см. Step 2) не противоречат этому: `EMAFast`=5 и `UseVolume`=1
воспроизводят чужие голоса один в один; расхождение по `EMASlow` (2/4 здесь против 3/4 в
`trend_hump`) — единственная неровность, и она не меняет вердикт, поскольку правило арбитра
завязано на pooled OOS, а не на повторное большинство по оси.

Отдельно стоит зафиксировать: pooled OOS этой темы (2.243) — **самый высокий pooled OOS среди
всех восьми тем, пройденных на SFIN** (entry 1.363, trend 1.380, trend_hump 1.382, screen 1.472,
vol_window 1.000, volume 1.195, day 1.689, trend_volume 2.243). Это прямое числовое подтверждение
того, зачем тема вообще заведена: связка тренда и объёмного гейта работает сильнее, чем любой из
двух рычагов по отдельности.

## Step 4 — сверка с двумерным опорным замером §6.2

Опорный замер (полное 36-месячное окно, поверх дефолтов ядра, `EMAFast` 5–8 × `EMASlow` 12–25):

- 5×12 → 1.574/57 (DD 8 970 ₽)
- 5×20 → 1.415/102
- 8×15 → 1.453/106 (DD 11 388 ₽)
- 8×12 → 1.320/95

Вся эта область держит PF 1.27–1.57 при просадке 9–12 тыс ₽.

Узлы-победители walk-forward по фолдам — (5,15), (5,25), (5,20), (8,15). Все четыре пары лежат
**внутри** заявленной области `EMAFast` 5–8 × `EMASlow` 12–25 (узлы 5×25 и 5×20 — на верхней
границе диапазона `EMASlow`, но не выходят за него). Геометрическое совпадение подтверждено: и
`trend_hump`-калибровка (Task 5), и эта связочная тема независимо приходят к тому же
трендовому «горбу».

**Прямого числового сравнения по ₽-просадке провести нельзя.** Опорный замер §6.2 снят на полном
36-месячном окне одной точкой (StopDailyATR/TPDailyATR дефолты, `UseVolume` не варьировался) и
даёт максимальную просадку в рублях. Walk-forward-отчёт этой темы даёт только `OOS MaxDD%` по
каждому 6-месячному test-окну отдельно (4.18% / 2.22% / 5.18% / 3.13%), без единой ₽-цифры на
полном окне и без разбивки по узлам — это разные единицы измерения на разных окнах, смешивать их
напрямую было бы некорректно. Косвенно цифры совместимы: OOS-просадки по фолдам умеренные
(2.22–5.18%), что не противоречит утверждению §6.2 о «зоне сниженной просадки», но формальной
сверки ₽-в-₽ эта тема дать не может — это фиксируется прямым текстом, а не подгоняется под
ожидание.
