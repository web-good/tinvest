фолдов из 4**; ничья 2/2 большинством не считается; иначе поле остаётся на дефолте ядра. Таблица
перепроверена построчно против `_comment` всех `cal_*.json` — **расхождений с исходной сборкой

## 2. Риск-гейт A — пройден с большим запасом

Эффективная защита = `min(StopDailyATR=0.5, TrailDailyATR при UseTrail=1)`. Поскольку `UseTrail=0`,
эффективная защита равна самому стопу — **0.5 ATR**. По таблице выживаемости TRNFP (n=760) узел 0.5
даёт **91.3%** будних дней при пороге 30% — гейт пройден с большим запасом, ограничивать нечего;
потолок гейта 1.0 не был достигнут ни одним принятым полем.

для протокола зафиксировано, что узел 3 (край сетки) и внутренний узел 5 на этой оси практически
неразличимы.

**Общий вывод по плато: ПЛАТО НЕ СУЩЕСТВУЕТ ни по одному из пяти проверяемых полей, кроме
