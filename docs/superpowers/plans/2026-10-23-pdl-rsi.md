# pdl_rsi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backtest-only long strategy `pdl_rsi` on 15m bars: hourly RSI(6) < 30 arms, a 15m RSI(6) cross of 30 upward with the bar's low in the PDL ± 0.4 daily ATR zone buys the next open; breakeven on the hourly RSI crossing 50, exit on the hourly RSI crossing 70.

**Architecture:** A new pure, stateless `core` package, the same shape as `pdl_zone/strategy/core`: on each bar `Decide` rebuilds the hourly series from the 15m window, replays the current date's setup automaton and either buys (flat) or manages the exits (in a position). Helpers are copied from `pdl_zone` (dailies, PDL, ATR, volume, room) and `drop_bounce` (hour aggregation, `crossUp`), never shared. A registry binding with no ticker packages wires it into `cmd/backtest`.

**Tech Stack:** Go 1.25, `pkg/indicators` (`RSISeries`, `ATR`), the scalping engine (`scalping/strategy`, `scalping/model`), `internal/domain/backtest` engine.

**Spec:** `docs/superpowers/specs/2026-10-23-pdl-rsi-design.md`

## Global Constraints

- Work in a git worktree on a new branch `feat/pdl-rsi` from `main` (use superpowers:using-git-worktrees). The main checkout on `feat/hammer` has uncommitted work — never touch it.
- No change to any existing strategy package or shared code (`scalping/model`, `domain/backtest`, `pkg/indicators`). Copy helpers instead.
- Only `Minutes15`; the registry rejects every other interval.
- Every `Params` field is `int` or `float64` (grid calibration by reflection).
- Defaults: `RSIPeriod` 6, `RSIArm` 30, `RSIEntry` 30, `RSIGate` 50, `RSIBreakeven` 50, `RSIExit` 70, `ZoneATR` 0.4, `VolumeMult` 1.5, `VolBars` 20, `MinRoomATR` 0.6, `DailyATRPeriod` 14.
- Exit reason codes: `SL` (initial stop), `TRAIL` (stop after the breakeven move), `RSI` (hourly RSI exit). Never `BE`.
- Entry and exit reason texts in Russian, like the neighbours.
- No look-ahead: the hourly RSI only on completed hours, the signal on a closed 15m bar, the buy at the next bar's open (`EntryAtNextOpen`).
- Quality gate: `./bin/mage ci` (lint + `go test -race ./...` + mock drift). Build check: `go build ./internal/... ./pkg/... ./cmd/...`.

## Review Focus

1. RSI warm-up zeros: `indicators.RSISeries` returns 0 before index `period` — a 0 must never arm (RSI < 30) or count as "below 30" for the stop. Expect no entry on a short window.
2. A position whose entry is older than the visible window: the breakeven must still fire on a 50 cross inside the window and must not crash on a missing entry bar.
3. An hour missing its :45 bar (a gap in data): the hour completes at the first bar of a later hour, and the arm/gate/exit checks see it exactly once.
4. The hour that completes on the signal bar itself crosses 50: the gate wins — no buy.
5. A gap down at the fill below the stop: the first `manage` call returns `SL` (the engine fills at `min(stop, open)`), no panic, no negative risk.

### Task 2: Entry — setup automaton, zone, filters, stop

**Files:**
- Create: `internal/service/trading_strategy/pdl_rsi/strategy/core/setup.go`

**Interfaces:**
- Consumes: Task 1 helpers.
- Produces:
  - `type setup struct { from, arm, signal int }` — `from` = first 15m bar of the arming hour (window start), `arm` = the bar that completed the arming hour, `signal` = the signal bar.
  - `func (s *Strategy) scan(ser series, hs []hourBar, rh, r15 []float64, k int, zoneLo, zoneHi float64) (setup, bool)` — replays bars of `dayKey(ser.t[k])` and returns the setup whose signal is bar `k`.
  - `func (s *Strategy) enter(md strategy.MarketData, sig model.Signal) model.Signal`.
  - `func stopOf(ser series, r15 []float64, st setup, entryLevel float64) float64` — min low over bars `from..signal-1` with `r15 < entryLevel`, and the signal bar's low.

Automaton (spec "Правила" + "Решения" 1–6), per bar `j` of the current date in order, state idle/armed:
- An hour `h` with `hs[h].done == j`, `h >= RSIPeriod`, `dayKey(hs[h].start) == date`:
  - armed and `RSIGate > 0` and `crossUp(rh[h-1], rh[h], RSIGate)` → idle (burn). Checked before the 15m cross on the same bar.
  - idle and `rh[h] < RSIArm` → armed, `from = hs[h].first`, `arm = j`. A further hour < 30 while armed changes nothing.
- Armed, `j > arm`, `j >= RSIPeriod+1`, `crossUp(r15[j-1], r15[j], RSIEntry)`:
  - `ser.l[j]` outside `[zoneLo, zoneHi]` → stay armed;
  - inside → the signal: burn (idle) whatever happens; if `j == k` return it.
- `enter` then requires, in order: `entryAllowed` (weekday, buy bar same date), room (`MinRoomATR`), volume over `from..k`, `stop > 0 && stop < close`. Any failure → no buy (the setup is already burnt by the replay). On success: `Kind Buy`, `StopLoss = stop`, `TakeProfit = 0`, `ATR = atr`, `Level = pdl`, `FillBy = t[k] + step`, `EntryReason` in Russian with the arming hour (time, RSI), the 15m cross (prev → cur), PDL and zone bounds, the stop and which bar set it, room and volume when on.

### Task 3: Exits — stop, breakeven, hourly RSI exit

**Files:**
- Create: `internal/service/trading_strategy/pdl_rsi/strategy/core/exits.go`
- Test: `internal/service/trading_strategy/pdl_rsi/strategy/core/exits_test.go`

**Interfaces:**
- Consumes: `hourBars`, `hourCloses`, `crossUp`, `strategy.Position{PurchasePrice, StopLoss, EntryTime}`.
- Produces: `func (s *Strategy) manage(md strategy.MarketData, sig model.Signal) model.Signal`, `func (s *Strategy) breakevenHit(md strategy.MarketData, hs []hourBar, rh []float64) bool`.

Rules:
- `breakevenHit`: `RSIBreakeven > 0` and some hour `h >= RSIPeriod` with `hs[h].done < n-1` (known before the current bar), `!md.Times[hs[h].last].Before(pos.EntryTime)` (the hour ends at or after the fill bar; when `EntryTime` is before `md.Times[0]` every hour in the window qualifies), and `crossUp(rh[h-1], rh[h], RSIBreakeven)`.
- `stop = pos.StopLoss`; when `breakevenHit`, `stop = max(stop, pos.PurchasePrice)` and the code is `TRAIL`, else `SL`.
- Order: `low <= stop` → Sell, `Reason` `SL`/`TRAIL`, `StopLoss = stop`; then, when `RSIExit > 0` and the current bar completes hour `h` (`hs[h].done == n-1`), `hs[h].last` not before `EntryTime`, and `crossUp(rh[h-1], rh[h], RSIExit)` → Sell, `Reason "RSI"`, at the close. No target, no end-of-day exit.
