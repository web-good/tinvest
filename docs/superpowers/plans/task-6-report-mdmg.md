## Вырожденные фолды

Порог (global-constraints.md / §4 спеки): меньше пяти сделок OOS **или** ни одной убыточной сделки.

- **Фолд 3 — ВЫРОЖДЕН**: 3 сделки OOS (< 5).
- **Фолды 1, 2, 4 — не вырождены** (9, 7, 9 сделок, все ≥ 5). Довод по правдоподобию, что убыточная
  сделка в каждом из них есть (тот же метод, что в `task-5-report-mdmg.md`): в
  `internal/domain/backtest/metrics.go:42-49` печатный артефакт `ProfitFactor = GrossProfit`
  возникает только при `GrossLoss == 0` и тогда равен валовому выигрышу **в рублях** — числу
  порядка тысяч. Значения OOS PF фолдов 1, 2, 4 (1.247, 2.008, 5.267) — обычные безразмерные
  отношения, а не суммы такого порядка, значит `GrossLoss > 0` в каждом из трёх, т.е. убыточная
  сделка в каждом фолде есть по правдоподобию. Дополнительно у фолда 1 семь выигрышных из девяти при
  PF 1.247 (не крайнее значение) — совместимо только с наличием проигрышных сделок в знаменателе.

**Один вырожденный фолд (3) — из голосования исключён; засчитываются 3 валидных голоса из 4.**
Пул (28 сделок) считается по всем четырём фолдам, включая вырожденный, как того требует
global-constraints («вердикт по схеме выносится по pooled OOS, оговорка записывается») —
оговорка: 3 из 28 сделок пула (10.7%) дал вырожденный фолд 3.

Два из трёх валидных фолдов (1 и 4) выбрали **FreshDayATR = 0.2** (> 0), т.е. большинство валидных
голосов (но не большинство 3/4 в целом) склоняется к ненулевому значению узла, который по
опорному замеру (Step 4, ниже) заводит вход на первый бар дня и даёт 19 входов в часы 02–06 против

активируется голосованием этой темы; Task 11 Step 6 должен явно проверить гейт C, если поле
`FreshDayATR` всё же будет взято ненулевым при сборке узла по другим соображениям.
