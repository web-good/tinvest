# RTKMP, Task 11 — сборка точки первого круга, риск-гейты и стоп-условие

**Дата:** 2026-09-05. Окно 2023-09-05 … 2026-09-05, схема 36/12/6 (четыре фолда), контроль 24/12/3.
Спека: `docs/superpowers/specs/2026-09-05-rtkmp-rsi-pullback-prep-design.md`.

## 1. Голоса тем поле за полем

Правило: поле берётся из темы, которая его меряет, и принимается только при большинстве **≥ 3
фолдов из 4**; ничья 2/2 большинством не считается; иначе поле остаётся на дефолте ядра.

| Поле | Тема | Голоса фолдов | Решение |
|---|---|---|---|
| `RSIPeriod` | entry | 4, 3, 6, 3 | дефолт **4** (большинства нет) |
| `RSILower` | entry | 25, 10, 35, 20 | дефолт **30** (все четыре разные) |
| `RSIUpper` | exit | 50, 45, 50, 65 | дефолт **70** (50 дважды — не большинство) |
| `EMAFast` | trend | 40, 5, 3, 3 | дефолт **10** (3 дважды) |
| `EMASlow` | trend | 75, 75, 50, 50 | дефолт **100** (ничья 2/2) |
| `DailyATRPeriod` | — | не измеряется | дефолт **14** |
| `UseDayATRGate` | screen | 1, 1, 1, 1 | **1** — единогласно, совпало с дефолтом |
| `FreshDayATR` | day | 0, 0, 0, 0 | **0** — стабильно, совпало с дефолтом |
| `SpentDayATR` | day / day_spent | 0.7, **0.9, 0.9, 0.9** | **0.9 ПРИНЯТО** (большинство 3/4; дефолт 0.8) |
| `StopDailyATR` | risk | 2.0, 2.0, 1.3, 1.0 | дефолт **0.5** (большинства нет) |
| `TPDailyATR` | risk | 0.2, 0.5, 0.15, 0.2 | дефолт **0.6** (0.2 дважды) |
| `UseVolume` | screen | 0, 1, 1, 0 | дефолт **0** (ничья 2/2) |
| `VolBaseDays` | volume | 3, 3, 10, 3 | дефолт **14** — большинство есть, но гейт выключен, поле инертно |
| `VolLookbackBars` | vol_window | 1, 1, 1, 32 | дефолт **3** — то же: гейт выключен, поле инертно |
| `VolMult` | volume / vol_window | 3/2.5/2.5/1 и 1.2/1.2/1.2/1 | дефолт **1.2** (совпало с большинством vol_window) |
| `UseRSIExit` | trail | 1, 1, 1, 1 | **1** — стабильно, совпало с дефолтом |
| `UseTrail` | trail | ось зафиксирована на 1 | **0** — большинства по дистанции нет |
| `TrailDailyATR` | trail | 0.3, 0.5, 1.0, 0.7 | **0** (все четыре разные) |

**Точка отличается от дефолтов ядра РОВНО ОДНИМ полем: `SpentDayATR` 0.9 вместо 0.8.** Это самый
скупой результат сборки в каталоге, и он не случайность: девять из одиннадцати тем разошлись по
фолдам полностью. Причина видна в числах фолдов — in-sample PF обучающих окон доходит до 12.805
(тема `entry`, фолд 2) при OOS 1.099, то есть каждое обучающее окно находит свой угол широкой
сетки, и правило большинства эти находки отвергает. Так правило и должно работать.

**Отдельная запись по теме `risk`:** все четыре фолда голосовали за стоп **1.0 и шире**
(2.0, 2.0, 1.3, 1.0), то есть капкан широкого стопа виден в каждом обучающем окне, а не только на
точечном замере. Три из четырёх голосов лежат выше потолка риск-гейта A и были бы отвергнуты
гейтом, даже если бы большинство сложилось. Правило большинства и риск-гейт A дали здесь один и тот
же ответ.

**Отдельная запись по теме `exit`:** это самый дорогой отказ калибровки на RTKMP. Точечно
`RSIUpper` 45 → 1.760/177 и 50 → 1.744/169 против 70 → 1.313/142; три фолда из четырёх голосовали
за 45–50, но правило требует **одно** значение в трёх фолдах, а не диапазон, поэтому поле осталось
в 0.45 PF от максимума оси.

## 2. Риск-гейт A — пройден

**Работа первого круга остановлена пунктом 3.** Задачи прода по первому кругу не выполняются.

Что именно поймал контроль: контрольная схема стоит на последних 24 месяцах и режет их на четыре
трёхмесячных OOS-куска, поэтому обвал последнего полугодия (инструмент −29.7%) весит в ней два
фолда из четырёх вместо одного из четырёх. Пул при этом тонкий — 23 сделки, из них один фолд
вырожден (одна сделка, PF 922.110, в пользу тикера не засчитывается), а последний фолд даёт
0.092 на четырёх сделках.

**Пункт 5 (реальный круг издержек 0.24%) точка проходит с запасом** — это ровно то, чего не смогли
дефолты ядра (1.002 in-sample). Отказ произошёл не по издержкам, а по режиму последнего полугодия.

## 6. Соседи плато по единственному принятому полю

| `SpentDayATR` | in-sample PF / сделок | max DD | pooled OOS 36/12/6 |
|---|---|---|---|
| 0.8 (дефолт, нижний сосед) | 1.313 / 142 | 11.70% | 1.354 / 95 |
| **0.9 (точка)** | **1.598 / 111** | **6.19%** | **1.744 / 71** |
| 1.0 (верхний сосед) | 1.500 / 82 | 6.28% | 1.669 / 53 |

Плато существует: 0.9 и 1.0 различаются по pooled OOS на **0.075** — это больше порога 0.05,
поэтому правило разрешения ничьих не применяется, и в точку идёт узел с большим pooled OOS (0.9).
Нижний сосед (дефолт 0.8) заметно хуже по обеим схемам и вдвое хуже по просадке.

Пул стоит на месте (111 → 110 → 110), PF растёт на 0.61, просадка растёт лишь на 1.6 пункта. Форма
капкана та же, что на SPBE: **гейт B его не ловит**, потому что просадка почти не портится; режет
только гейт A, а в этом круге ещё и правило большинства.

## 8. Вердикт первого круга

- **Планка НЕ ВЗЯТА.** Тема `entry`: критерий A взят (pooled OOS 1.669 на 79 сделках), критерий B
  провален (`RSILower` 25/10/35/20). Тема `trend`: критерий A взят (1.576 на 85), критерий B
  провален (`EMASlow` 75/75/50/50, ничья).
- **Стоп-условие СРАБОТАЛО по пункту 3** (0.662 на контрольной схеме 24/12/3).
- Оба риск-гейта пройдены, третий контур лучше baseline по всем пяти числам.
- В прод по итогам первого круга RTKMP не заводится. Маршрут «дефолты ядра» (прецедент TGKA)
  недоступен: дефолты дают 0.530 на той же контрольной схеме.
- Открытый маршрут — **второй круг перекалибровки на однородном 24-месячном окне** (прецедент
  SOFL): в первом полугодии окна сессия вдвое короче (19 баров против 35), и обучающие фолды
  первого круга учатся на другом режиме торгов.
