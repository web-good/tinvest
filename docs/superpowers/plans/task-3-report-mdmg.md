### Вырожденные фолды

Порог: меньше 5 OOS сделок ИЛИ ни одной убыточной OOS сделки. Число OOS сделок по фолдам — 17, 13,
25, 10 — все ≥ 5.

Проверка «ни одной убыточной сделки» — по явному разбору (движок при `GrossLoss == 0` печатает
`ProfitFactor = GrossProfit` в рублях, `internal/domain/backtest/metrics.go:42-49`):

- **Фолд 3 (PF 0.455, 25 сделок)** — PF < 1. По определению `GrossProfit / GrossLoss < 1` требует
  `GrossLoss > 0` — убыток есть **строго, по построению**.
- **Фолды 1, 2, 4 (PF 1.086 / 2.650 / 1.868)** — PF ≥ 1, строго доказать нельзя формулой. Если бы
  убытков не было, `GrossLoss == 0` и PF равнялся бы валовому выигрышу в рублях. Масштаб сделки
  MDMG виден по пулу: лучшая/худшая сделка пула 2754.31/-2483.11 ₽ — одна сделка составляет тысячи
  рублей. Чтобы PF (1.086, 2.650 или 1.868) оказался равен `GrossProfit` в рублях, валовый выигрыш
  всех сделок фолда должен был бы составить **1.09 ₽, 2.65 ₽ или 1.87 ₽** соответственно — на
  порядки меньше, чем даёт даже одна реальная сделка такого масштаба. Это математически
  невозможно при 17, 13 и 10 реальных сделках — **вывод по правдоподобию** (тот же метод, что в
  отчёте RAGR), убыточная сделка во всех трёх фолдах есть.

**Вырожденных фолдов нет** — по фолду 3 вывод строгий, по фолдам 1, 2, 4 — правдоподобный вывод по
порядку величины. Все четыре голоса засчитываются.

### Голоса по осям (4 фолда)

- **`UseDayATRGate`**: 3 фолда (1, 2, 4) за значение 1, 1 фолд (3) за значение 0 — **большинство 3/4
  за 1**.
- **`UseVolume`**: 2 фолда (1, 2) за значение 0, 2 фолда (3, 4) за значение 1 — **ничья 2/2, большинства
  3/4 нет**.

Голос за `UseVolume`=1 в теме `screen` измеряет объём только при дефолтном множителе `VolMult`=1.2
(ось не свипуется здесь) — строгий множитель испытывают темы `volume` и `vol_window` (Task 7).

### Сверка с ожиданием (§6.3 спеки / Step 4 брифа: ожидается 1×0)

**Частичное подтверждение.** Ось `UseDayATRGate` подтверждает ожидание: большинство фолдов (3/4:
1, 2, 4) выбрало гейт **включённым** (1), как в ожидаемом узле 1×0 и как у дефолтов ядра. Ось
`UseVolume` ожидание **не подтверждает и не опровергает** — голоса разделились ровно поровну (2/2:
фолды 1, 2 за 0; фолды 3, 4 за 1), большинства 3/4 в пользу ожидаемого 0 нет. В отличие от полного
разворота голосов у RAGR (там 3/4 против ожидания), у MDMG результат — неопределённость ровно на
объёмной оси при устойчивой поддержке дневного гейта.

Замер in-sample из `_comment` грида (полное окно, §6.3 спеки) даёт для узла 1×0 (дефолт ядра)
1.546/134 — лучший из четырёх узлов по PF. Пофолдовые IS PF у выбравших 1×0 фолдов (1.471 и 1.578)
согласуются с этим направлением. Фолд 3 (единственный убыточный OOS-фолд, PF 0.455, train
2025-03-27—2026-03-27) выбрал 0×1 — по всей видимости, режим без дневного гейта на его train-окне
переобучился под локальный участок, который затем не подтвердился на OOS-тесте
2026-03-27—2026-06-27. Решение по сборке узла — за Task 11/13, здесь фиксируются только голоса.
