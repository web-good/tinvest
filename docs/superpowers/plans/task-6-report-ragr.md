## Вердикт (для Task 10 / Task 11)

- **Pooled OOS PF = 1.322** / пул **49** сделок (все 4 фолда не вырождены, зачитываются целиком).
- **`FreshDayATR`**: голоса 0.05/0.3/0.2/0.2 — **большинства 3/4 нет**; ни один фолд не остался на
  дефолте 0.
- **`SpentDayATR`**: голоса 0.5/2.0/1.5/2.0 — **большинства 3/4 нет**; ни один фолд не остался на
  дефолте 0.8.
- Ни один из двух опорных in-sample узлов, отдельно поднятых брифом как потенциальные рычаги
  (`FreshDayATR`=0.05, `SpentDayATR`∈{1.25,1.5,2.0}), не набрал большинства per-fold отбором:
  `FreshDayATR`=0.05 получил только 1 голос (фолд 1); `SpentDayATR`∈{1.25,1.5} — 1 голос (фолд 3, и
  то 1.5, не 1.25); `SpentDayATR`=2.0 — 2 голоса (фолды 2, 4), недостаточно для большинства.
- Тема `day` в целом **уходит от обоих дефолтов ядра** согласованно по направлению (все 4 фолда:
  `FreshDayATR`>0, `SpentDayATR`>0.8), но **без совпадения на конкретной величине** ни по одной оси —
  сигнал есть («более раннее и более широкое дневное окно помогает»), точного узла majority не даёт.
  Task 11 при сборке поля дневного гейта не может опереться на majority этой темы буквально и должен
  явно решить, как трактовать согласие по направлению без согласия по величине (см. §5.2 методики).
- `FreshDayATR`>0 на всех 4 выбранных фолдами узлах (0.05, 0.3, 0.2, 0.2) — открывает вход на первый
  бар дня на каждом из них; проверка запрета входов в выходные/02–06 для любого из этих узлов,
  случись он выбранным в Task 11, обязательна (пункт 7 стоп-условия).
