## Step 1: зоны второго круга по голосам фолдов первого круга

Зоны выбраны по фактическим голосам фолдов 24/12/3 задач 3–10, включая арбитров. Рельеф in-sample и
соседи плато Task 11 зонами не служат. Вырожденные фолды записаны в скобках и не голосуют.

Правило заведения зоны: не меньше трёх невырожденных голосов лежат в полосе из трёх соседних узлов оси
первого круга. Шаг — половина шага первого круга в этом месте оси, целочисленные поля — целые узлы.
База тем — дефолты ядра, как у тем первого круга (прецедент RAGR). Узел-якорь — значение дефолта или
точки первого круга. Он даёт фолду остаться на базе, и соседом по правилу ±1 шаг не считается.

Тем пять из шести разрешённых. Каждое поле свипует ровно одна тема.

## Замечания

1. **Зона `SpentDayATR` сдвинута с кандидата брифа.** Бриф называл [0.8, 0.85, …, 1.1]. Фактические
   голоса — day 3/4 за 1.25 и trend_spent 1, 1. Узел 1.25 выбросить значило бы выбирать по провалу
   точки 1, а не по голосам (§5.14: «по фактическим голосам фолдов»). Зона взята 0.95–1.375 с якорем
   0.8. На итог это не повлияло: тема дала два вырожденных фолда из четырёх.
2. **Узел `EMAFast` 5** добавлен к кандидату брифа [1, 2, 3, 4]. За него два невырожденных голоса:
   trend ф1 и trend_low ф1. Ни один фолд второго круга его не выбрал.
3. **Зона B `EMASlow` (42–50)** добавлена к кандидату брифа (18–30). Голоса первого круга двугорбые:
   по пять невырожденных голосов в каждой полосе, а в полосе 45–50 стоит большинство канонической
   trend. Правило зоны B то же, что у брифа для зоны A: половинный шаг, округлённый до целых узлов.
   Ни один фолд второго круга зону B не выбрал.
4. **`FreshDayATR` не свипуется**, хотя полоса 0.2 голосами есть (пять невырожденных голосов из семи).
   Бриф фиксирует поле на 0 из-за гейта C. Поле, заведённое в сторону 0.2, почти наверняка ушло бы
   на 0 в Task 11 Step 6.
5. **Стоп в `cal2_risk` зафиксирован на 0.8**, а не на дефолтных 0.5. Голоса цели первого круга сняты
   при стопе 2.0, а 0.8 — значение, с которым цель пошла бы в точку. Контрольный узел цели 1.0 нужен
   `TestRSIPullbackGridControlPoints`. Ни один фолд его не выбрал.
6. **Маршрут CNRU после гейта B.** Task 11 Step 3 описывает маршрут CNRU для точки, совпавшей с
   дефолтами сразу при сборке. Здесь совпадение возникло после возврата стопа по Step 4. Прочтение
   «пересчитать с Step 3» ведёт к тому же Step 3 и к тому же маршруту. Числа walk-forward взяты из
   Task 1 (2026-09-26), одиночный прогон снят сегодня и совпал с Task 1 побайтово.
7. **Гейт B дефолтов — ровно на пороге** (9 153.17 ₽ = порог). Это не совпадение: порог и есть
   просадка дефолтов.
