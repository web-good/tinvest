# hammer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backtest-only strategy `hammer`: on Hour1 bars buy the next open after a hammer candle whose own close has RSI(5) < 30; stop 0.5 daily ATR, target half of yesterday's daily range, exit also on RSI(5) > 70.

**Architecture:** Pure, stateless core in `internal/service/trading_strategy/hammer/strategy/core` implementing `strategy.Strategy` (`Ticker/Lookback/Decide`), shaped like `pdl_zone/strategy/core`. Ticker packages return literals; `internal/service/backtest/hammer_registry.go` binds them; `cmd/backtest` routes `-strategy hammer` with `EntryAtNextOpen`.

**Tech Stack:** Go 1.25, `tinvest/pkg/indicators` (`RSISeries`, `ATR`), scalping `model`/`strategy` packages.

**Spec:** `docs/superpowers/specs/2026-10-21-hammer-design.md`

## Global Constraints

- Hour1 only; any other interval → registry error `hammer runs on Hour1, not <interval>`.
- Defaults: `RSIPeriod` 5, `RSIZone` 30, `RSIExit` 70, `StopDailyATR` 0.5, `TargetRangeMult` 0.5, `DailyATRPeriod` 14. All Params fields int or float64.
- Do not edit anything under `pdl_reclaim/` or `pdl_zone/`. Do not stage the owner's uncommitted edits (`git add -p` for `CLAUDE.md` and `cmd/backtest/main.go`; only hammer hunks).
- Calendar in MSK (`Europe/Moscow`, UTC fallback); dailies drop Sat/Sun before ATR and yesterday's range; the hourly series is used as supplied (RSI over every bar).
- Reasons in Russian; exit `Reason` codes `SL`, `TP`, `RSI`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Known pre-existing failure: `pdl_zone/strategy/nvtk` `TestLiteralIsPinned` fails on the owner's uncommitted edit (MinRoomATR 0.5 vs 0.2). Not ours; verify with `go test ./internal/service/trading_strategy/hammer/... ./internal/service/backtest/... ./cmd/backtest/...` and `./bin/golangci-lint run ./internal/service/trading_strategy/hammer/... ./internal/service/backtest/... ./cmd/backtest/...`.

## Review Focus

1. Gap at the fill: fill opens far below the signal close — the stop must be 0.5 ATR under the *fill*, never above it; the target the frozen distance above the fill (test `TestLevelsFollowTheFill`).
2. Last bar of the day (evening 23:00 bar): buy bar falls on the next date — no signal (test `TestNoEntryWhenBuyBarIsNextDate`).
3. Weekend dailies leaking into ATR / yesterday's range on Monday — must use Friday's daily (test `TestMondayUsesFridayRange`).
4. `TargetRangeMult` 0 or `RSIExit` 0 switch their exit off without breaking the other exits (test `TestExitsSwitchOff`).
5. Doji / zero-range bar: never a hammer (test `TestIsHammer` cases).
