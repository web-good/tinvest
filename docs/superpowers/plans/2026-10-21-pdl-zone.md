# pdl_zone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backtest-only strategy `pdl_zone` on 5m: a zone/break setup at yesterday's low, entry on the first closed green MACD histogram bar, stop under the 5-bar low, R target.

**Architecture:** New package `pdl_zone/strategy/core`, pure and stateless between bars like `pdl_reclaim/strategy/core`: on every bar it replays the current date's bars through a small state machine to find whether the current bar is a signal. A ticker literal package `nvtk`, a backtest registry and a `cmd/backtest` case wire it in. `pdl_reclaim` is not touched.

**Tech Stack:** Go 1.25, `pkg/indicators` (`MACD`, `ATR`), `scalping/model` + `scalping/strategy` interfaces, `internal/service/backtest` bindings.

**Spec:** `docs/superpowers/specs/2026-10-21-pdl-zone-design.md`

## Global Constraints

- Not a single line of `internal/service/trading_strategy/pdl_reclaim/` changes.
- Bars: only `enum.Minutes5`; trading only Mon–Fri MSK; the buy bar's date equals the signal bar's date.
- Defaults: `EntryZone 1, EntryBreak 1, ZoneATR 0.2, MACDFast 8, MACDSlow 21, MACDSignal 9, VolumeMult 1.5, VolBars 15, StopBars 5, MinStopATR 0.2, TargetR 2, DailyATRPeriod 14`.
- Every `Params` field is `int` or `float64` (reflection grid).
- Signal on the closed bar; stop and target off the signal close; fill at next open (`EntryAtNextOpen`).
- Entry/exit reasons in Russian, like the sibling strategies. Code comments in English, matching `pdl_reclaim`.
- Quality gate: `./bin/mage ci` green.

## Review Focus

1. Gap down through the stop at the fill — engine fills at next open; `manage` must still exit on the first bar whose low ≤ stop (test `TestStopHitOnFirstBarAfterFill`).
2. Bars without volumes (`md.Volumes` nil / misaligned) — volume filter fails closed, no buy (test `TestNoVolumesNoEntry`).
3. Too little history for MACD (`len < MACDSlow+MACDSignal`) or daily ATR — no entry, no panic (test `TestShortHistoryNoEntry`).
4. Signal on the last bar of the date (buy bar on the next date) — no entry (test `TestLastBarOfDateNoEntry`).
5. Weekend dailies must not become PDL (test `TestWeekendDailyIgnored`, fixture dailies like `pdl_reclaim`'s `dailyBars`).

  - `func DefaultParams() Params`
  - `func NewWithParams(ticker string, step time.Duration, p Params) *Strategy` implementing `strategy.Strategy` (`Ticker`, `Lookback`, `Decide`).

**State machine (`setup.go`)** — `func (s *Strategy) scan(ser series, hist []float64, k int, pdl, zoneTop float64) (st setup, ok bool)` walks bars of bar k's date from the first one up to k:
```
state idle → armed(arm=j, kind=zone|break) → after signal: needRed → idle on hist<=0
at bar j (state idle or armed):
  if c[j] < pdl and (idle or kind==zone): arm=j, kind=break           // break re-arms (spec 4)
  else if idle and l[j] <= zoneTop and c[j] >= pdl: arm=j, kind=zone
at bar j (state armed): if hist[j] > 0 → signal at j; state=needRed
at bar j (state needRed): if hist[j] <= 0 → idle (the same bar may then re-arm? no: arming is checked on the next bar)
```
Order inside one bar: arming first, then the signal check (the arm bar may be the signal, spec 2). `ok` only when the signal bar is k and the setup kind's flag is on. A zone setup with `EntryZone 0` never arms (but a break still can). A signal burns the setup whatever happens next (spec 3).

**enter**: weekday + buy bar same date → PDL and daily ATR → `hist = macd − signal` over all bars (`indicators.MACD`) → `scan` → volume: average of main-session volumes over `[arm..k]` > `VolumeMult` × `averageVolume(ser, arm, VolBars)`; no main-session bar in the window or no volumes → fail; `VolumeMult 0` → off → stop = min `l[k-StopBars..k-1]` (fewer than StopBars bars before k → no entry); if `close − stop < MinStopATR×atr` → `stop = close − MinStopATR×atr` → `target = close + TargetR×(close − stop)` → `Signal{Kind: SignalBuy, StopLoss, TakeProfit, ATR, Level: pdl, FillBy: t[k]+step, EntryReason}`.

**manage**: stop from `pos.StopLoss` (frozen at signal); `low <= stop` → SL, else `high >= pos.TakeProfit` → TP. Nothing else.

**Lookback**: `max(MACDSlow+MACDSignal)*3 + StopBars, VolBars main-session bars back over up to a weekend) + one day`; exact formula left to the implementer, test that it is ≥ `(MACDSlow+MACDSignal)*3`.
