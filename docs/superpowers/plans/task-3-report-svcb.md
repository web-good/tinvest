### Вырожденные фолды (уточнение после ревью Task 4)

Порог: меньше 5 OOS сделок ИЛИ ни одной убыточной OOS сделки. Число OOS сделок по фолдам — 37, 52,
87, 15 — все ≥ 5.

Проверка «ни одной убыточной сделки» — НЕ по конечности PF (движок при `GrossLoss == 0` печатает
`ProfitFactor = GrossProfit`, конечный PF сам по себе убыток не доказывает —
`internal/domain/backtest/metrics.go:42-49`), а по явному разбору:

- **Фолды 1, 2, 3 (PF 0.977 / 0.889 / 0.827)** — PF < 1. Такое значение при `GrossLoss == 0`
  означало бы, что весь валовый выигрыш фолда меньше 1 ₽, что для 37/52/87 реальных сделок SVCB
  (сотни–тысячи ₽ за сделку) невозможно. `GrossLoss > 0` **гарантирован математически**.
- **Фолд 4 (PF 1.384, 15 сделок)** — PF ≥ 1, строго доказать нельзя. Если бы убытков не было,
  PF равнялся бы валовому выигрышу в рублях — при 15 сделках такого размера (лучшая/худшая
  сделка пула 2598.48/-2628.28) это было бы число порядка десятков тысяч, а не 1.384. Значение
  на несколько порядков меньше правдоподобного валового выигрыша — **вывод по правдоподобию**:
  убыток почти наверняка есть, строгого доказательства нет.

**Вырожденных фолдов нет** — по фолдам 1–3 вывод строгий, по фолду 4 — правдоподобный вывод по
порядку величины. Все четыре голоса засчитываются.

### Голоса по осям (4 фолда)

Узел, выбранный на каждом train-окне (Gate × Volume):

- Фолд 1: **1 × 0**
- Фолд 2: **0 × 1**
- Фолд 3: **0 × 0**
- Фолд 4: **1 × 1**

Каждый из четырёх фолдов выбрал СВОЙ, отличный от остальных, узел — представлены все четыре
комбинации 2×2 ровно по одному разу.

- **UseDayATRGate**: 2 фолда (1, 4) за значение 1, 2 фолда (2, 3) за значение 0 — **ничья 2/2**, ни
  одно значение не набирает большинства 3/4.
- **UseVolume**: 2 фолда (2, 4) за значение 1, 2 фолда (1, 3) за значение 0 — **ничья 2/2**, ни одно
  значение не набирает большинства 3/4.

### Сверка с ожиданием (§6.3 спеки / Step 4 брифа: ожидается 1×0)

**Ожидание НЕ подтвердилось.** Узел 1×0 победил только на фолде 1 из четырёх; остальные три фолда
выбрали три других узла (0×1, 0×0, 1×1) — по одному разу каждый. Обе оси дали идеальную ничью 2/2
без большинства ни в одну сторону — заметно слабее, чем предупреждал бриф («точечная разница PF
0.015 между 1×0 и 0×1 на полном окне — голоса могут разойтись»): голоса разошлись не частично, а
полностью, вплоть до того что все четыре узла представлены на разных train-окнах по одному разу.
Это согласуется с оговоркой в `_comment` грида: «направление эффекта объёмного гейта переворачивается
в зависимости от дневного гейта» — тема `screen` в данном случае не даёт устойчивого сигнала ни по
одной из двух осей на скользящих train-окнах, несмотря на то что узел 1×0 лучший на полном
36-месячном окне (in-sample). Pooled OOS PF темы (0.926/191) ниже полнооконного baseline (0.951/130)
— OOS-пул темы объединяет OOS-сегменты всех фолдов, где на каждом окне побеждал СВОЙ узел, а не
фиксированный 1×0, поэтому прямое сравнение этих двух чисел не показательно.
