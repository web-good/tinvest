### Вырожденные фолды

Порог: меньше 5 OOS сделок ИЛИ ни одной убыточной OOS сделки. Число OOS сделок по фолдам — 26, 26,
22, 7 — все ≥ 5.

Проверка «ни одной убыточной сделки» — не по конечности PF (движок при `GrossLoss == 0` печатает
`ProfitFactor = GrossProfit`, конечный PF сам по себе убыток не доказывает —
`internal/domain/backtest/metrics.go:42-49`), а по явному разбору:

- **Фолды 2, 3 (PF 0.761 / 0.796)** — PF < 1. По определению `GrossProfit / GrossLoss < 1` требует
  `GrossLoss > 0` — убыток есть **строго, по построению**.
- **Фолд 1 (PF 1.310, 26 сделок)** и **фолд 4 (PF 2.412, 7 сделок)** — PF ≥ 1, строго доказать
  нельзя формулой. Если бы убытков не было, `GrossLoss == 0` и PF равнялся бы валовому выигрышу в
  рублях. Пул сделок даёт масштаб сделки RAGR: лучшая/худшая сделка пула 4893.06/-3833.98 ₽, т.е.
  одна сделка — сотни-тысячи рублей. Чтобы PF (1.310 или 2.412) оказался равен `GrossProfit` в
  рублях, валовый выигрыш всех сделок фолда должен был бы составить **1.31 ₽ или 2.41 ₽** — на
  порядки меньше, чем даёт даже одна реальная сделка такого масштаба. Это математически
  невозможно при 26 и 7 реальных сделках соответственно — **вывод по правдоподобию** (тот же
  метод, что в отчёте SVCB), убыточная сделка в обоих фолдах есть.

**Вырожденных фолдов нет** — по фолдам 2, 3 вывод строгий, по фолдам 1, 4 — правдоподобный вывод по
порядку величины. Все четыре голоса засчитываются.

### Голоса по осям (4 фолда)

Узел, выбранный на каждом train-окне (Gate × Volume):

- Фолд 1: **0 × 1**
- Фолд 2: **0 × 1**
- Фолд 3: **0 × 1**
- Фолд 4: **1 × 0**

- **UseDayATRGate**: 3 фолда (1, 2, 3) за значение 0, 1 фолд (4) за значение 1 — **большинство 3/4
  за 0**.
- **UseVolume**: 3 фолда (1, 2, 3) за значение 1, 1 фолд (4) за значение 0 — **большинство 3/4 за
  1**.

Собранный по большинству узел — **0 × 1** (дневной гейт выключен, объёмный включён).

### Сверка с ожиданием (§6.3 спеки / Step 4 брифа: ожидается 1×0)

**Ожидание НЕ подтвердилось.** Бриф ожидал узел **1×0** (дневной гейт включён, объёмный выключен —
дефолт ядра). Фолды 1–3 (три из четырёх, ровно порог большинства) единогласно выбрали
противоположный узел **0×1**; только фолд 4 (самый маленький, 7 OOS-сделок) выбрал ожидаемый 1×0.
Итоговое большинство по обеим осям — **0×1**, зеркально противоположное ожиданию брифа.

Это как раз тот случай, который Step 4 брифа предписывает зафиксировать прямым текстом: **узел 0×1
в точку не пройдёт гейт B**. По точечному замеру in-sample из `_comment` грида (§6.3 спеки), узел
0×1 даёт просадку **12 937 ₽** — выше порога гейта B (**9 642.93 ₽** / 9.03%, полнооконный baseline
на 2026-09-26). Даже при более высоком in-sample PF (1.314/136 против 1.231/77 у 1×0) узел 0×1 не
пройдёт сборку по риск-гейту B. Решение — за Task 11: собирать ли точку на 1×0 (дефолт ядра, гейт B
пройден, но не поддержан большинством голосов фолдов) или документировать расхождение голосов и
гейта B как отдельный вывод по RAGR.
