- **UseDayATRGate**: 4 фолда из 4 за значение 1 — **единогласно**.
- **UseVolume**: 4 фолда из 4 за значение 0 — **единогласно**.

Узел-победитель **1×0** взял все четыре фолда без исключений — не большинство, а полное
единогласие по обеим осям одновременно.

Пофолдовые пулы (85 сделок, PF 1.247) численно совпадают с полнооконным walk-forward
дефолтов ядра из §3 спеки (пул 85, PF 1.247) — ожидаемо, поскольку победивший на каждом
train-окне узел 1×0 идентичен дефолтам ядра, и тема `screen` в данном случае воспроизводит
чистый walk-forward baseline.
