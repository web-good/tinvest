# Team Lead Agent Design Specification

**Date:** 2026-05-13  
**Author:** Claude Code  
**Status:** Approved

## Overview

Создание суб-агента тимлида для координации выполнения задач с использованием системы superpowers. Агент будет распределять задачи, планировать их выполнение и координировать работу специализированных суб-агентов в изолированных контекстах.

## Core Architecture

### 1. Team Lead Agent (Координатор)

**Ответственности:**
- Декомпозиция пользовательских задач на подзадачи
- Распределение задач между агентами
- Выбор appropriate навыков superpowers для каждой задачи
- Отслеживание прогресса через возвращаемые результаты
- Обработка ошибок и создание альтернативных планов
- Формирование итогового отчета

**Ограничения:**
- Не может изменять файлы напрямую
- Не может выполнять команды записи (Write, Edit)
- Только чтение, анализ и координация

### 2. Специализированные суб-агенты

#### Planning Agent
- Использует навык `superpowers:writing-plans`
- Создает детальные планы выполнения
- Работает в новом контекстном окне

#### Implementation Agent
- Использует навыки: `golang-pro`, `golang-patterns`, `golang-testing`
- Выполняет кодирование без прав записи
- Предоставляет решения для проверки

#### Testing Agent
- Использует навык `golang-testing`
- Проводит тестирование решений
- Отчеты о покрытии и результатах

#### Review Agent
- Использует навык `superpowers:verification-before-completion`
- Проверяет качество выполнения
- Возвращает фидбэк

### 3. Система координации

#### Механизм создания контекстов
- Каждый суб-агент запускается в новом изолированном контексте
- Контекст включает необходимые данные для выполнения задачи
- Результаты передаются обратно тимлиду

#### Протокол взаимодействия
```
Team Lead → [task_data] → Sub Agent
Sub Agent → [result_data] → Team Lead
Team Lead → [retry_data] → Sub Agent (при ошибках)
```

## Process Flow

### Основной алгоритм:

1. **Прием задачи**
   ```
   User → Team Lead: "Реализовать новую торговую стратегию"
   ```

2. **Декомпозиция**
   ```
   Team Lead анализирует и создает:
   - Задача 1: Анализ требований
   - Задача 2: Создание архитектуры
   - Задача 3: Реализация кода
   - Задача 4: Написание тестов
   - Задача 5: Ревью и валидация
   ```

3. **Планирование**
   ```
   Для каждой задачи:
   - Выбор навыка superpowers
   - Создание контекста для суб-агента
   - Запуск в новом окне
   ```

4. **Исполнение**
   ```
   Параллельное выполнение там, где возможно
   Последовательное выполнение при зависимостях
   ```

5. **Сбор результатов**
   ```
   Team Lead собирает результаты
   Формирует финальный отчет
   При необходимости - повторяет с корректировками
   ```

### Обработка ошибок

1. **Первичная попытка**
   - Запуск суб-агента с первоначальным планом
   - Ожидание результата

2. **Анализ ошибки**
   - Если неудача → анализ причины
   - Создание альтернативного подхода

3. **Повторное выполнение**
   - Новый план → новый контекст → повторный запуск
   - Максимум 3 попытки на задачу

## Integration with Superpowers

### Приоритет навыков:
1. **Process skills** (brainstorming, debugging) - определяют подход
2. **Implementation skills** (golang-pro, patterns) - выполняют работу
3. **Verification skills** (verification) - проверяют результат

### Адаптивное применение:
- Team Lead анализирует тип задачи
- Выбирает навыки в зависимости от контекста
- Может изменять порядок при необходимости

## Technical Implementation

### Структура данных для координации:
```json
{
  "task_id": "uuid",
  "parent_task": "uuid",
  "description": "string",
  "skill": "skill_name",
  "agent_type": "planning|implementation|testing|review",
  "context": {},
  "status": "pending|in_progress|completed|failed",
  "result": {},
  "attempts": 0,
  "max_attempts": 3
}
```

### Коммуникация между агентами:
- Через временные файлы в `.claude/team-lead/`
- Структура: `/tmp/claude-teamlead-{session}/`
- Автоматическая очистка после завершения
