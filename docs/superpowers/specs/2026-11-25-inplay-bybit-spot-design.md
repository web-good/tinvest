# Часовая сводка inplay для Bybit Spot

Каждый полный час скринер inplay отправляет в свою Telegram-тему сводку по активным спотовым парам Bybit с котировкой в USDT. В момент сканирования он отбирает пары с оборотом за скользящие 24 часа строго выше 80 000 000 USDT. Для них он рассчитывает NATR(14) по закрытым свечам M5 на границу часа. Пара проходит при значении от 0,4% до 1,7% включительно. Оба сравнения выполняются до округления значений для сообщения.

## Подход

Выбран отдельный воркер в пакете inplay. Он использует расписание часовой сводки и тему скринера. Существующий воркер Binance и MOEX рассчитывает относительный объём и средний размах для двух окон. Применение этих условий к Bybit изменило бы согласованный состав выборки. Скринер плотностей Bybit и его торговые профили находятся вне задачи.

## Расчёт и выдача

Оборот берётся из поля turnover24h. NATR в процентах равен 100 × ATR Уайлдера за 14 периодов / цену последнего закрытия. Свечи упорядочиваются по времени. Для расчёта нужна непрерывная история до границы отчёта. Строка сводки содержит символ, оборот в USDT и NATR. Предлагаемый порядок выдачи — по убыванию оборота, при равенстве — по символу.

Проверки охватывают точное равенство порогу оборота, обе границы NATR, значения за пределами диапазона, исключение текущей незакрытой свечи и отсутствие необходимых данных.
