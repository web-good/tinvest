# Density: входы по тикерам из алертов

`DENSITY_LIVE_FOLLOW_SCREENER=true` расширяет допуск к входам: постоянный список
`DENSITY_LIVE_TICKERS` плюс тикеры с успешно отправленным density-алертом за
текущий запуск приложения. Доставка алерта добавляет ID инструмента в общий
потокобезопасный реестр; не вызывает покупку напрямую. Независимый детектор
по-прежнему проверяет плотность, выдержку, профиль, стакан, торговый статус,
зону интереса, cooldown и собственные средства (в реальной торговле).
При false остаются прежние фиксированный список и подписки на ленту.

Расширенный режим использует ту же отобранную вселенную и лимит стаканов, что
скринер (до 80). Для исполнения достаточно стаканов и Info: новые подписки на
ленту по всем инструментам не создаются. В paper вход и тейк исполняются только
при доступной ликвидности соответствующей стороны стакана, с учётом цены
лимита, задержки и объёма. Сопровождение позиций не зависит от реестра алертов.
Профили обновляются без сброса позиций; состав подписок фиксируется на запуск,
как в существующих live/paper runners. После перезапуска допуск дополнительных
тикеров накапливается заново. Реальная торговля автоматически не включается.
