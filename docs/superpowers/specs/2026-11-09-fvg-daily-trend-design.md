# Дневной тренд-фильтр FVG imbalance

## Intent

Фильтр тренда стратегии `fvg_imbalance` должен использовать дневные свечи вместо текущих H4-свечей. Период `HTFTrendEMA` сохраняет численное значение и трактуется в количестве дневных свечей: например, `120` означает EMA по 120 дневным свечам.

## Goals / non-goals

- При включённом фильтре разрешать лонг, только когда последняя полностью закрытая дневная цена выше своей EMA.
- Использовать только завершённые дневные данные, уже доступные стратегии через `DailyCloses`.
- Значение периода `0` по-прежнему отключает фильтр.
- Не пересчитывать существующие значения параметра и не менять правила входа/выхода.

## Approaches

- Считать EMA на дневных закрытиях с прежним числом периода — выбранный вариант; сохраняет параметр и его значение, меняется только таймфрейм.
- Пересчитать период для близкого временного горизонта H4 — отклонён, потому что выбран период в дневных свечах без преобразования.

## Constraints and implementation calls

- Решение принимается по последнему элементу `DailyCloses`; движок уже поставляет только завершённые дневные свечи.
- Недостаточная история или невалидные значения закрытий запрещают вход при включённом фильтре.
- Переименование `HTFTrendEMA` и перенастройка сеток не входят в эту небольшую смену поведения.
- Обновить описание стратегии и комментарии к параметру, чтобы явно указывать дневной таймфрейм.
