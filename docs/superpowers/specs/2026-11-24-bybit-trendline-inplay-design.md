# Фильтр inplay для Bybit Trendline

## Выбор метрики

Для оценки активности рассматривались средний размах пятиминутной свечи и размах цены за весь час. Выбран первый вариант. Он измеряет амплитуду движения внутри отдельных свечей.

## Правило

Для каждой выбранной спотовой пары на отметках :00 и :30 UTC берём последние 12 закрытых пятиминутных свечей, включая свечу, которая закрылась в момент проверки. Пара получает статус inplay до следующей проверки при одновременном выполнении двух условий.

- Среднее арифметическое значений `100 × (high − low) / low` по 12 свечам составляет не менее 1%.
- Средний объём этих свечей строго выше среднего объёма пятиминутной свечи той же пары за понедельник–пятницу предыдущей календарной недели по UTC.

При неполных данных новые входы блокируются. Выходные исключаются только из расчёта недельного фона. Для самого фильтра используются свечи 5 минут при любом таймфрейме стратегии.

## Применение

В режимах backtest и watch используется одно правило. При формировании сигнала и исполнении ожидающего входа учитывается статус на соответствующий момент. На границе получаса сначала применяется новая оценка. Снятие статуса отменяет ожидающий вход. Стратегия продолжает отслеживать трендовые линии и сопровождает открытую позицию по её стопу и цели.
