# Откат по RSI в тренде (`rsi_pullback`) — дизайн стратегии

Дата: 2026-07-28. Статус: спека согласована, реализация не начата.

## Задача

Backtest-only лонговая стратегия на 30-минутных барах: покупка отката внутри восходящего
тренда. Тренд задаёт пара EMA, момент входа — заход короткого RSI в критическую нижнюю зону,
выход — заход того же RSI в критическую верхнюю зону. Позиция не переносится на следующий
день, в выходные не торгуем.

Механизм — классический Connors-style: короткий RSI (4–6 периодов) на 30m опускается в зону
перепроданности часто, поэтому гипотеза строится на **частоте входов**, а не на размере
отдельной сделки. Фильтр тренда отсекает откаты в падающем рынке, где «дешёвое становится
дешевле».

## Отличие от соседней стратегии `rsi_ema`

`rsi_ema` (15m, не смержена, ждёт калибровки) входит по кресту RSI **вверх** через 50 при
`EMA10 > EMA50` — это продолжение импульса. `rsi_pullback` входит по кресту RSI **вниз** через
нижний порог при `EMAFast > EMASlow` — это покупка отката. Гипотезы противоположны, поэтому
стратегии разведены по отдельным пакетам: `rsi_ema` не трогаем, чтобы уже полученные по ней
прогоны остались сравнимыми.

## Решения, принятые владельцем

- **Только лонг**; движок бэктеста шорты и не поддерживает.
- **Вход — событие, а не состояние:** крест RSI вниз через нижний порог, а не «любой бар, где
  RSI ниже порога». Один заход в зону даёт один вход, серии повторных сигналов нет.
- **Выход по RSI — вход в верхнюю зону**, то есть крест вверх через верхний порог, а не выход
  из неё вниз. Фиксируем отскок в перекупленность, не дожидаясь разворота.
- **Защита обязательна:** ATR-стоп плюс тайм-стоп по числу удержанных баров.
- **Калибровка — на GAZP**, проверка переносимости — NVTK и RUAL.
- **Вердикт по результатам калибровки выносит владелец сам**, прогоняя бэктест лично. Работа
  по этой спеке заканчивается на коде, сетке и документации с готовыми командами; формальных
  порогов приёмки спека не фиксирует.
- Тариф «Трейдер»: комиссия 0.05% за сторону, **0.1% за круг** — совпадает с дефолтом бэктеста
  (`-commission 0.0005`), переопределять его нельзя.

## Правила стратегии

Таймфрейм — 30 минут. Все временные правила — в минутах от полуночи `Europe/Moscow`
с откатом на UTC, как во всех стратегиях репо.

### Вход

Все условия проверяются на закрытии одного бара; при выполнении всех — покупка:

1. Бар внутри окна входа: будний день, `SessionStartMin ≤ время < SessionEndMin`
   (07:00–17:00 MSK). Выходные отсекаются явной проверкой дня недели, а не только
   отсутствием свечей.
2. `EMAFast > EMASlow` на этом баре — тренд вверх.
3. Крест RSI вниз через нижний порог: `RSI[i-1] ≥ RSILower` и `RSI[i] < RSILower`.
4. Позиции нет.

Повторный вход в тот же день разрешён: если после выхода RSI снова пересечёт нижний порог
внутри окна входа, стратегия входит снова. Отдельного кулдауна нет — от перезаходов защищает
сама природа креста: пока RSI сидит ниже порога, второго сигнала не возникает.

### Выходы

Работают в любое время, включая бары вне окна входа. Порядок — это приоритет: если на одном
баре сработало несколько условий, засчитывается первое из списка.

1. **`SL`** — минимум бара достиг уровня `вход − StopATR × ATR(на баре входа)`. Стоп имеет
   приоритет над сигнальным выходом: внутри бара он срабатывает раньше.
2. **`RSI`** — крест RSI вверх через верхний порог: `RSI[i-1] ≤ RSIUpper` и `RSI[i] > RSIUpper`.
3. **`TIME`** — позиция удерживается `MaxHoldBars` баров. `MaxHoldBars = 0` выключает выход.
4. **`EOD`** — последний бар торгового дня (`DayEndMin`): позиция закрывается принудительно,
   на следующий день не переносится.

### Параметры

Все поля — только `int` и `float64`: рефлексивная грид-калибровка (`applyField`) другие типы
не перебирает.

| Параметр | Дефолт | Смысл | Единица |
|---|---|---|---|
| `RSIPeriod` | 4 | длина RSI | бары |
| `RSILower` | 15 | нижняя критическая зона, крест вниз = вход | пункты RSI |
| `RSIUpper` | 70 | верхняя критическая зона, крест вверх = выход | пункты RSI |
| `EMAFast` | 10 | быстрая EMA | бары |
| `EMASlow` | 100 | медленная EMA | бары |
| `StopATR` | 1.2 | стоп = вход − `StopATR` × ATR | множитель ATR |
| `ATRPeriod` | 14 | длина ATR | бары |
| `MaxHoldBars` | 8 | тайм-стоп; 0 выключает | бары |
| `SessionStartMin` | 420 | начало окна входа (07:00 MSK) | минуты от полуночи |
| `SessionEndMin` | 1020 | конец окна входа (17:00 MSK) | минуты от полуночи |
| `DayEndMin` | 1380 | принудительное закрытие (23:00 MSK) | минуты от полуночи |

`EMASlow = 100` на 30m — это около пяти торговых дней: фильтр тренда среднесрочный, не дневной.

`Lookback = max(120, 2 × max(EMASlow, RSIPeriod, ATRPeriod) + 20)`. При `EMASlow = 200` это
420 баров, около 21 торговой сессии. Удвоение периода нужно, чтобы EMA успела сойтись: окно
короче периода даёт нулевой ряд, который молча провалил бы гейт тренда на весь прогон.

## Архитектура

Отдельный пакет, структурный клон `rsi_ema`. Соседние стратегии, движок бэктеста, walk-forward
и отчёты не меняются.

| Файл | Ответственность |
|---|---|
| `internal/service/trading_strategy/rsi_pullback/strategy/core/core.go` | `Params`, `DefaultParams`, `NewWithParams`, `Ticker`, `Lookback`, `Decide` → `enter`/`manage`, `Explain`. Чистая логика, ничего не знает о загрузке свечей |
| `.../core/core_test.go` | table-driven тесты входа, выходов, приоритета, сессионных границ, анти-lookahead |
| `internal/service/backtest/rsi_pullback_registry.go` | `RSIPullbackLookupOrGeneric` — биндинг ядра к движку, разбор частичного JSON поверх дефолтов |
| `internal/service/backtest/rsi_pullback_registry_test.go` | тесты биндинга и разбора частичного JSON |
| `internal/service/backtest/rsi_pullback_grid_test.go` | каждое имя поля сетки существует в `Params`; контрольные точки на месте |
| `cmd/backtest/main.go` | ветка `case "rsi_pullback"` и строка помощи флага `-strategy` |
| `data/params/rsi_pullback/grid.json` | фазовая сетка, 32 комбинации |
| `docs/rsi_pullback/strategy.md` | правила, таблица параметров, команды запуска |

Переиспользуются без изменений: `indicators.RSISeries`, `indicators.ATR`, `ema.Compute`,
`strategy.MarketData` / `strategy.Position`, движок и walk-forward.

Сессионные хелперы (окно входа, день недели, конец дня, определение шага бара) дублируют
аналогичные из `rsi_ema` — около 60 строк. Это принято сознательно: `rsi_ema` не смержена и
ждёт калибровки, а рефакторинг общего пакета ради недоказанной стратегии дороже дублирования.
Вынести общие хелперы имеет смысл только когда обе стратегии окажутся жизнеспособными.

## Сетка калибровки

Фазовая, как у соседних стратегий: каждая фаза перебирается поверх победителей предыдущей.

| Фаза | Поля | Значения | Комбинаций |
|---|---|---|---|
| `entry` | `RSIPeriod` × `RSILower` | 4/5/6 × 5/10/15/20 | 12 |
| `trend` | `EMAFast` × `EMASlow` | 5/10/20 × 50/100/200 | 9 |
| `exit` | `RSIUpper` | 60/70/80 | 3 |
| `risk` | `StopATR` | 0.8/1.2/1.6/2.0 | 4 |
| `hold` | `MaxHoldBars` | 0/4/8/12 | 4 |

Всего 32 комбинации. Контрольная точка «выключено» есть у `MaxHoldBars` (`0`). У `StopATR`
нуля намеренно нет: калибровка не должна иметь возможности выбрать торговлю без стоп-лосса,
хотя само ядро выключение стопа поддерживает (`StopATR = 0`).

Сессионные границы в сетку не входят: окно торговли — это условие задачи, а не подбираемая
ручка.

## Тестирование

TDD: сначала падающий тест, затем реализация. Обязательное покрытие:

- **каждый гейт входа отдельно и на границе**: `RSI` ровно на пороге входа не даёт, на шаг
  ниже — даёт; `EMAFast == EMASlow` входа не даёт. Проверка гейтов только экстремальными
  значениями не ловит сдвиг сравнения `<` против `<=` — на этом уже ловили прошлые ревью;
- **приоритет выходов**, включая бар, где сработали и стоп, и RSI-выход: побеждает стоп;
- **сессионные границы**: 06:59 и 17:00 входа не дают, выход в 22:30 работает, позиция не
  переживает `DayEndMin`, в выходные входов нет;
- **деградация**: данных короче `EMASlow` не хватает — входов нет, паники нет; нулевой или
  отрицательный `MaxHoldBars` выключает тайм-стоп, а не роняет логику;
- **отсутствие lookahead**: решение на баре `i` не зависит от того, где обрезано окно. Сигнал
  и RSI-зависимые поля сравниваются строго, ATR-зависимый стоп — с относительным допуском:
  `indicators.ATR` — рекурсия Уайлдера с неограниченной памятью, её значение зависит от длины
  прогрева окна, но не от будущих баров (движок подаёт окно фиксированной длины `Lookback()`).

Гейт каждой задачи — зелёный `./bin/mage ci` и коммит.

## Команды запуска

```
# разведочный прогон на дефолтах
go run ./cmd/backtest -ticker GAZP -strategy rsi_pullback -interval Minutes30 \
  -out ./reports/GAZP_rsipb -months 24

# диагностика одного бара
go run ./cmd/backtest -ticker GAZP -strategy rsi_pullback -interval Minutes30 \
  -months 24 -explain "2026-05-14 14:30"

# walk-forward калибровка
go run ./cmd/backtest -ticker GAZP -strategy rsi_pullback -interval Minutes30 \
  -calibrate data/params/rsi_pullback/grid.json -out ./reports/GAZP_rsipb \
  -months 24 -train-months 12 -test-months 3 -metric profit_factor -min-trades 40

# проверка переносимости победивших параметров без пере-калибровки
go run ./cmd/backtest -ticker NVTK -strategy rsi_pullback -interval Minutes30 \
  -params data/params/rsi_pullback/gazp_cal.json -out ./reports/NVTK_rsipb -months 24
```

Комиссию (`-commission`, дефолт `0.0005` за сторону) не переопределять.

## Что вне рамок

- Live-торговля: стратегия backtest-only, в `internal/app`, live-раннеры и Telegram не
  подключается.
- Шорты, пирамидинг, частичные выходы, трейлинг-стоп, перенос позиции через ночь.
- Старший таймфрейм (HTF): фильтр тренда живёт на рабочем 30-минутном таймфрейме.
- Вердикт о жизнеспособности: его выносит владелец по своим прогонам.
