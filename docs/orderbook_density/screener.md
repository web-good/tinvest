# Скринер плотностей стакана

Скринер наблюдает биржевые bid-уровни рублёвых акций MOEX и отправляет сообщения отдельному получателю Telegram. Торговые заявки он не выставляет. По умолчанию он выключен.

Создайте отдельный чат или супергруппу, добавьте существующего бота и предоставьте ему право отправлять сообщения. Получите числовой ID чата через Telegram Bot API (например, из `getUpdates` после сообщения в чат) и задайте его в `DENSITY_CHAT_ID`. Не публикуйте токен или содержимое ответа API. Для форумной темы задайте также её числовой ID в `DENSITY_TOPIC_ID`; значение `0` отправляет в чат без указания темы. Установите `DENSITY_ENABLED=true` и перезапустите приложение. При включении без chat ID конфигурация отклоняется.

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `DENSITY_ENABLED` | `false` | Включить постоянный воркер |
| `DENSITY_CHAT_ID` | `0` | Отдельный чат, обязателен при включении |
| `DENSITY_TOPIC_ID` | `0` | Необязательная тема чата |
| `DENSITY_MAX_BOOKS` | `80` | Максимум стаканов |
| `DENSITY_MAX_TRADES` | `10` | Максимум подписок на сделки |
| `DENSITY_BOOK_DEPTH` | `50` | Запрашиваемая глубина стакана |
| `DENSITY_MIN_RUBLES` | `5000000` | Минимальный денежный объём уровня |
| `DENSITY_MIN_MULTIPLE` | `5` | Минимальная кратность медиане соседних уровней |
| `DENSITY_MAX_DISTANCE` | `0.01` | Максимальное относительное расстояние от лучшего bid |
| `DENSITY_MIN_NEIGHBORS` | `5` | Минимум уровней для медианы |
| `DENSITY_MAX_NEIGHBORS` | `10` | Максимум ближайших уровней для медианы |
| `DENSITY_PERSISTENCE` | `1m` | Минимальное время наблюдения |
| `DENSITY_FRESHNESS` | `3s` | Максимальный возраст стакана и промежуток без свежего снимка |
| `DENSITY_MIN_TURNOVER` | `100000000` | Минимальный средний дневной оборот, ₽ |
| `DENSITY_MAX_LOT_PRICE` | `30000` | Максимальная стоимость лота, ₽ |
| `DENSITY_HISTORY_INTERVAL` | `1s` | Минимальный интервал запросов истории |

Список акций обновляется раз в сутки по максимум 20 завершённым дневным свечам, минимум 10; оборот приблизительно равен close × объём в лотах × размер лота. При ошибке обновления сохраняется прежний список. Закрытая торговая сессия не исключает инструмент из списка, но до подтверждения нормального торгового статуса сигналы запрещены.

Плотность — агрегированный объём на цене, а возраст показывает время наблюдения скринером, а не возраст отдельной заявки. Несвежий или неконсистентный стакан, остановка торгов и переподключение сбрасывают наблюдение; отсутствие обновлений дольше порога свежести также сбрасывает его, даже при работающем соединении. Лента сделок подключается к максимум десяти кандидатам; сообщение показывает только период её покрытия. Повторное сообщение по той же цене допускается после нового эпизода и 30 минут с предыдущей успешной отправки. Данные состояния хранятся в памяти и сбрасываются при рестарте.
