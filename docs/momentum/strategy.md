# Стратегия «Momentum» — как она работает

Документ объясняет логику стратегии простым языком: что она делает, когда покупает,
когда продаёт и за что отвечает каждый параметр. Источник истины — код
`internal/service/trading_strategy/momentum/strategy/core/core.go`; здесь — его
человеческое описание. Значения параметров приведены для RUAL
(`.../strategy/rusal/rusal.go`). Стратегия ticker-agnostic: любую акцию можно добавить
своим пакетом с откалиброванными параметрами, а незнакомый тикер работает на
generic-дефолтах.

---

## 1. Идея в одном абзаце

Стратегия **только покупает** (long-only) и торгует на **часовом** таймфрейме. Она ловит
**начало восходящего импульса в растущем тренде**: цена должна быть выше длинной EMA (тренд
вверх), индикатор **MACD** только что дал бычий сигнал (зелёная линия пересекла красную снизу
вверх), на свече **повышенный объём** (движение «настоящее», а не вялое), и при этом по
**дневному ATR** ещё остался запас хода — то есть день не «выходил» весь свой типичный
диапазон, цене есть куда расти. Когда всё совпало — покупка. Выход: либо по **жёсткому
стоп-лоссу** под структурной поддержкой, либо по **тейк-профиту** на фиксированном расстоянии
2R (вдвое больше риска). Опционально вместо фиксированного TP можно включить **трейлинг**,
чтобы «ехать» в сильном тренде.

Это классический **trend-momentum**: входим по направлению тренда на подтверждённом импульсе,
с заранее известными риском и целью.

---

## 2. Когда стратегия ПОКУПАЕТ (вход)

Вход (`Buy`) происходит, только если позиции нет и **одновременно** выполнены все условия,
оценённые на закрытой часовой свече:

| # | Условие | Смысл |
|---|---|---|
| 1 | **Тренд вверх:** часовой `close > EMA(EMAPeriod)` | Покупаем только над длинной скользящей средней — не ловим падающий рынок. |
| 2 | **Бычий кросс MACD:** на прошлой свече MACD ≤ сигнальной, на текущей MACD > сигнальной. При `MACDBelowZeroOnly=1` — дополнительно MACD должен быть **под нулём** в момент кросса. | Импульс только что развернулся вверх. Кросс под нулём = разворот после отката (меньше входов в перегретом рынке). |
| 3 | **Повышенный объём:** объём последней свечи `> VolMultiplier × средний объём за VolLookback баров` | Движение поддержано объёмом — «вертикальный» интерес, а не тонкий рынок. |
| 4 | **Остался запас дневного ATR:** внутридневной ход `(TodayHigh − TodayLow) < MaxDailyATRUsed × дневной ATR` | День ещё не прошёл свой типичный диапазон — цене есть куда идти вверх. Если ход почти исчерпан, вход блокируется. |
| — | **Анти-черн:** часовой `ATR ≥ MinATRFrac × цена` | Не торгуем, когда инструмент почти не движется (иначе комиссии съедают всё). |

Условия легко расширяются: каждое — отдельная проверка с собственным параметром, новые
фильтры добавляются без переписывания ядра (см. §6 про заготовки).

---

## 3. Где стоят СТОП-ЛОСС и ТЕЙК-ПРОФИТ

Оба уровня считаются в момент входа и **замораживаются** (не «сползают» вслед за ценой).

- **Стоп-лосс (SL):** `SL = минимум за SwingLowWindow баров − SLMult × ATR(час)`.
  То есть чуть ниже ближайшей структурной поддержки, с буфером в долю ATR.
  `risk = цена входа − SL`.
- **Тейк-профит (TP):** `TP = цена входа + TakeProfitRR × risk`.
  При `TakeProfitRR = 2.0` цель вдвое дальше стопа (2R) — соотношение риск/прибыль 1:2.

Дополнительная проверка качества: вход отклоняется, если `(TP − цена) < MinRR × risk`
или если `risk ≤ 0`.

---

## 4. Когда стратегия ПРОДАЁТ (выход)

Пока позиция открыта, на каждом баре проверяется (приоритет сверху вниз):

1. **Стоп-лосс** — если минимум бара `≤ SL`. Налив по `min(SL, open)` — учитывает гэп вниз
   (если бар открылся ниже стопа, фиксируем реальный убыток от гэпа). Причина: `SL`.
2. **Тейк-профит** — если максимум бара `≥ TP`. Налив по `max(TP, open)` — лимитная заявка,
   гэп вверх исполняется лучше. Причина: `TP`.
3. **Трейлинг** (только если `UseTrail = 1`) — chandelier-стоп
   `максимум за ChandelierWindow − TrailMult × ATR`, взводится после прибыли в
   `TrailArmATR × ATR(вход)`. Если включён — заменяет фиксированный TP, давая «ехать» в тренде.
   Причина: `TRAIL`.

Если в одном баре задеты и SL, и TP — приоритет у **стоп-лосса** (консервативно).

## 5. Параметры стратегии

Все параметры — `int`/`float64` (флаги — `int` 0/1), поэтому их можно перебирать
grid-калибровкой. Значения ниже — стартовые дефолты (для RUAL калибруются отдельно).

| Параметр | Дефолт | За что отвечает |
|---|---|---|
| `EMAPeriod` | 200 | Период длинной EMA — фильтр тренда (часовой). |
| `MACDFast` | 12 | Быстрая EMA для MACD. **Подбирается под акцию.** |
| `MACDSlow` | 26 | Медленная EMA для MACD. **Подбирается под акцию.** |
| `MACDSignal` | 9 | Период сигнальной линии MACD. **Подбирается под акцию.** |
| `MACDBelowZeroOnly` | 1 | 1 = кросс засчитывается только под нулевой линией; 0 = любой бычий кросс. |
| `VolLookback` | 20 | Окно среднего объёма. |
| `VolMultiplier` | 1.2 | Во сколько раз объём свечи должен превышать средний. |
| `DailyATRPeriod` | 14 | Период дневного ATR (для «запаса хода»). |
| `MaxDailyATRUsed` | 0.6 | Макс. доля дневного ATR, которую может «выходить» день до входа. Меньше → строже. |
| `ATRPeriod` | 14 | Период часового ATR (стопы, анти-черн). |
| `SwingLowWindow` | 10 | Окно поиска структурного минимума под стоп. |
| `SLMult` | 0.5 | Буфер стопа в долях ATR ниже структурного минимума. |
| `TakeProfitRR` | 2.0 | Цель в кратности риска (2.0 = 2R). |
| `MinRR` | 1.5 | Мин. допустимое риск/прибыль; вход хуже — отклоняется. |
| `MinATRFrac` | 0.003 | Анти-черн: мин. ATR как доля цены (≤0 отключает). |
| `UseTrail` | 0 | 1 = вместо фикс-TP вести трейлинг. |
| `TrailMult` | 2.5 | Дистанция chandelier-трейла в ATR. |
| `ChandelierWindow` | 20 | Окно максимума для трейла. |
| `TrailArmATR` | 1.0 | Прибыль (в ATR входа), после которой взводится трейл. |
| `CooldownBars` | 0 | Заготовка: пауза в барах после стопа (0 = выкл). |
| `DailyTrendPeriod` | 0 | Заготовка: доп. фильтр «выше дневной EMA» (0 = выкл). |

---

## 6. Что в отчёте бэктеста

По каждой сделке журнал показывает выставленные **SL** и **TP**, посчитанные **ATR** (часовой
и дневной) и **причину входа словами**, например:

> `Тренд↑ (close 32.6000 > EMA200 32.0748); MACD бычий кросс под нулём (-0.0362); объём > 1.2×ср(20); дневной ATR-запас 72% (прошло 0.1950 из 0.7066); ATR(ч)=0.1144, ATR(д)=0.7066; SL=32.2078 (-0.3922); TP=33.3844 (+0.7844, 2R)`

---

## 7. Как запустить

```sh
# одиночный прогон на дефолтах
go run ./cmd/backtest -ticker RUAL -strategy momentum -interval Hour1 -months 12

# калибровка под акцию (MACD-периоды — индивидуально)
go run ./cmd/backtest -ticker RUAL -strategy momentum -calibrate data/params/rusal/momentum_grid.json
```

Замечание: на бумаге в устойчивом даунтренде трендовая логика даёт мало входов — это
ожидаемое поведение фильтров, а не ошибка.

---

## 8. Заготовки на будущее (выключены по умолчанию)

- **`CooldownBars`** — не входить N баров после стоп-лосса (не лезть в «падающий нож»).
- **`DailyTrendPeriod`** — доп. конфлюэнс: цена выше дневной EMA.

Оба — отдельные параметры; ядро не переписывается при добавлении новых условий входа.
