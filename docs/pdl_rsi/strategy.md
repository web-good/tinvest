# pdl_rsi — крест часового RSI вниз через 30, вход по развороту стохастика

Бэктест-стратегия, только лонг, таймфрейм **только 1h** (`-interval Hour1`, другие cmd/backtest отклоняет). Позиция переносится через ночь и выходные. Код: `internal/service/trading_strategy/pdl_rsi/strategy/core`, привязка к бэктесту — `internal/service/backtest/pdl_rsi_registry.go`. Спека первой версии (15m): `docs/superpowers/specs/2026-10-23-pdl-rsi-design.md`. Живого раннера нет.

RSI — Уайлдер с периодом `HourRSIPeriod` по закрытиям часовых свечей. Стохастик — медленный (`StochK`, `StochSmooth`, `StochD`; по умолчанию 5, 3, 3): %K (на графике сплошная) — сырой %K за `StochK` баров, сглаженный средней за `StochSmooth`; %D (пунктир) — средняя %K за `StochD`. Сигналы — только по закрытым часовым свечам, покупка — по open следующей (`EntryAtNextOpen`).

## Вход

1. **Сигнал RSI** — закрытый час, на котором RSI пересёк `RSIArm` сверху вниз: предыдущий час той же даты МСК закрылся с RSI не ниже `RSIArm`, этот — ниже.
2. **Триггер** — первый закрытый час в пределах `StochBars` часов после сигнала RSI (сам час сигнала не в счёт), на котором %K пересёк %D снизу вверх ниже `StochCrossMax`: на прошлом часе %K ≤ %D, на этом %K > %D и %K < `StochCrossMax` (значит, и %D ниже). Крест на уровне `StochCrossMax` и выше триггером не считается и следующий крест не блокирует. Если в окне креста нет, сигнал сгорает. При нескольких сигналах RSI в окне берётся последний.
3. **Условия на триггере:**
   - RSI часа триггера не выше `RSITriggerMax`;
   - RSI ни на одном часе от сигнала RSI до триггера включительно не опускался ниже `RSIFloor` — слишком глубокий провал не покупаем;
   - тренд: close часа триггера строго выше прогретой EMA(`TrendEMA`) по часовым закрытиям;
   - необязательные фильтры (по умолчанию выключены): объём часа сигнала RSI, запас хода дня на триггере (см. таблицу);
   - свеча покупки (следующий час) лежит в ту же дату МСК, день — Пн–Пт и биржевой (см. «Неторговые будни»).
4. **Стоп и цель** — стоп `StopATR` дневных ATR (Уайлдер `DailyATRPeriod` по дневкам Пн–Пт, замороженный на сигнале) ниже цены покупки, но не дальше `MaxStopPct` процентов от цены (при большом ATR стоп подтягивается к этому потолку), цель — `TargetR` стопов выше неё. Сигнал несёт оба уровня от close триггера для риск-сайзинга (`-risk-pct`), позиция пересчитывает их от цены покупки.

**Фильтр объёма** сравнивает объём часа сигнала RSI со средним `VolBars` часов основной сессии (10:00–18:00 МСК, Пн–Пт биржевые даты) до него. Если этот час не из основной сессии, фильтр не пропускает вход.

**Неторговые будни.** В биржевой будний день первая часовая свеча начинается в 06:00 МСК. В будний праздник биржи (например, 31 декабря, 2 и 7 января) идут только дилерские сделки: свечи с 02:00, дневной свечи нет. Будняя дата, первая свеча которой в окне начинается раньше 06:00, считается неторговой: входов в неё нет, а её часы не попадают в базу `VolBars`. Выходные обрабатываются как выходные.

## Выход

По приоритету на каждом часе:

1. **SL** — `low ≤ стоп`; движок исполняет по `min(стоп, open)`.
2. **TP** — `high ≥ цель`; движок исполняет по `max(цель, open)`.
3. **STOCH** (по умолчанию выключен) — %K стохастика пересёк %D сверху вниз и на этом часе %K выше `StochExitAbove` (значит, и %D выше): продажа по close часа, причина `STOCH`.
4. **RSI** — часовой RSI пересёк `RSIExit` вверх: продажа по close часа, причина `RSI`.

Выхода в конце дня нет. Позиция переносится через выходные: дилерские часы выходных — обычные свечи для выхода.

## Параметры (`core.Params`)

| поле | по умолчанию | смысл |
|---|---|---|
| `HourRSIPeriod` | 6 | период часового RSI; 0 — входов нет |
| `RSIArm` | 30 | сигнал — крест часового RSI через это вниз |
| `RSIFloor` | 22 | нет входа, если RSI опускался ниже этого от часа сигнала RSI до триггера; 0 — без ограничения |
| `RSITriggerMax` | 50 | RSI часа триггера не выше этого; 0 — без ограничения |
| `RSIExit` | 70 | крест часового RSI вверх — выход; 0 — RSI-выхода нет |
| `StochExitAbove` | 0 | %K пересёк %D сверху вниз выше этого уровня — выход по close часа; 0 — выхода по стохастику нет |
| `StochK` | 5 | длина сырого %K; 0 — входов нет |
| `StochSmooth` | 3 | сглаживание %K; 0 — входов нет |
| `StochD` | 3 | длина %D; 0 — входов нет |
| `StochBars` | 4 | окно поиска креста %K над %D после сигнала RSI, часов; 0 — входов нет |
| `StochCrossMax` | 40 | крест засчитывается, только если %K на часе креста ниже этого; 0 — на любом уровне |
| `VolumeMult` | 0 | объём часа сигнала RSI выше `VolumeMult` × среднего `VolBars` часов основной сессии до него; 0 — фильтра нет |
| `VolBars` | 20 | длина базы объёма, часов |
| `MinRoomATR` | 0 | на триггере должно оставаться столько дневных ATR хода вверх (лой дня + ATR − close); 0 — фильтра нет |
| `StopATR` | 0.5 | стоп — столько дневных ATR ниже цены покупки; 0 — входов нет |
| `MaxStopPct` | 0 | потолок стопа — не дальше этого процента от цены, как бы ни был велик ATR; цель считается от урезанного стопа; 0 — без потолка |
| `TargetR` | 2 | цель — столько стопов выше цены покупки; 0 — цели нет |
| `TrendEMA` | 200 | close часа триггера строго выше EMA этого периода (EMA не прогрета — входа нет); 0 — фильтра нет |
| `DailyATRPeriod` | 14 | период дневного ATR |

Частичный JSON параметров ложится поверх дефолтов ядра (или литерала тикера, когда он заведён в `pdlRSIRegistry`).

## Запуск

```
go run ./cmd/backtest -ticker NVTK -strategy pdl_rsi -interval Hour1 -months 12 -risk-pct 1 -out ./reports/NVTK
```

Калибровка — скользящий walk-forward по стартовой сетке `data/params/pdl_rsi/grid_example.json`. Режима `-explain` у стратегии нет.
