# pdl_rsi — вход у вчерашнего лоя по кресту 15m RSI после просадки часового RSI

Бэктест-стратегия, только лонг, таймфрейм **только 15m** (`-interval Minutes15`, другие cmd/backtest отклоняет). Позиция переносится через ночь и выходные. Код: `internal/service/trading_strategy/pdl_rsi/strategy/core`, привязка к бэктесту — `internal/service/backtest/pdl_rsi_registry.go`. Спека: `docs/superpowers/specs/2026-10-23-pdl-rsi-design.md`. Живого раннера нет.

Часовые свечи собираются из 15m. Один период `RSIPeriod` задаёт и часовой, и 15m RSI (Уайлдер). Часовой RSI считается только по завершённым часам, сигнал — только по закрытой 15m свече, покупка — по open следующей (`EntryAtNextOpen`).

## Вход

1. **Взвод.** Завершённый час с часовым RSI ниже `RSIArm` взводит сетап. Пока сетап жив, следующие часы ниже `RSIArm` его не пересоздают, окно поиска не сдвигается.
2. **Окно поиска** начинается с первой 15m свечи часа взвода и идёт до сигнала; сигнал возможен только после завершения часа взвода.
3. **Сигнал** — закрытая 15m свеча, на которой 15m RSI пересёк `RSIEntry` снизу вверх, при условиях:
   - low свечи в зоне `PDL ± ZoneATR · ATR` (PDL — лой предыдущего торгового дня, ATR — дневной Уайлдер `DailyATRPeriod` по дневкам Пн–Пт);
   - гейт: часовой RSI не пересекал `RSIGate` снизу вверх с момента взвода;
   - фильтры объёма и запаса хода (см. таблицу) проходят;
   - свеча покупки (следующая) лежит в ту же дату МСК, день — Пн–Пт.
4. **Сгорание сетапа:** крест часового RSI через `RSIGate` вверх; сигнальный крест 15m RSI с low в зоне (купил он или не прошёл фильтр); смена даты МСК — сетап не переживает свою дату. Крест с low вне зоны сетап сохраняет.
5. **Стоп** — минимальный low среди 15m свечей окна поиска с RSI ниже `RSIEntry` и сигнальной свечи; он уходит в сигнал для риск-сайзинга (`-risk-pct`).

Ядро без состояния: на каждой свече автомат проигрывается заново по свечам даты.

## Выход

По приоритету на каждой свече:

1. **SL** — `low ≤ исходный стоп`; движок исполняет по `min(стоп, open)`.
2. **TRAIL** — после того как завершённый час после входа пересёк `RSIBreakeven` вверх, стоп переезжает в цену входа; срабатывание этого стопа — причина `TRAIL` (не `BE`).
3. **RSI** — на свече, завершающей час, часовой RSI пересёк `RSIExit` вверх: продажа по close, причина `RSI`.

Цели и выхода в конце дня нет.

**Ограничение окна безубытка.** Безубыток восстанавливается по истории в `Lookback` свечей, то есть примерно `holdDays` (10) рабочих дней. Если позиция живёт дольше, часы старше окна безубыток уже не видят: кресты RSIBreakeven в них не учитываются.

## Параметры (`core.Params`)

| поле | по умолчанию | смысл |
|---|---|---|
| `RSIPeriod` | 6 | период часового и 15m RSI; 0 — входов нет |
| `RSIArm` | 30 | часовой RSI ниже — взвод сетапа |
| `RSIEntry` | 30 | 15m RSI пересекает вверх — сигнал |
| `RSIGate` | 50 | часовой RSI не пересекал вверх с момента взвода; 0 — гейта нет |
| `RSIBreakeven` | 50 | крест часового RSI вверх переносит стоп в цену входа; 0 — безубытка нет |
| `RSIExit` | 70 | крест часового RSI вверх — выход; 0 — RSI-выхода нет |
| `ZoneATR` | 0.4 | полуширина зоны вокруг PDL в дневных ATR |
| `VolumeMult` | 1.5 | средний объём окна входа выше `VolumeMult` × среднего `VolBars` свечей основной сессии до него; 0 — фильтра нет |
| `VolBars` | 20 | длина базы объёма |
| `MinRoomATR` | 0.6 | на сигнале должно оставаться столько дневных ATR хода вверх; 0 — фильтра нет |
| `DailyATRPeriod` | 14 | период дневного ATR |

Частичный JSON параметров ложится поверх дефолтов ядра (или литерала тикера, когда он заведён в `pdlRSIRegistry`).

## Запуск

```
go run ./cmd/backtest -ticker NVTK -strategy pdl_rsi -interval Minutes15 -months 12 -risk-pct 1 -out ./reports/NVTK
```

Калибровка — скользящий walk-forward по стартовой сетке `data/params/pdl_rsi/grid_example.json`. Режима `-explain` у стратегии нет.
