# FVG imbalance: вход по стохастику

Стратегия работает только в бэктесте, открывает лонг по завершённым M30-свечам. Она ищет бычий FVG из трёх последовательных свечей: средняя свеча зелёная, её тело перекрывает разрыв между максимумом первой и минимумом третьей, а размер разрыва не меньше `MinGapATR` дневного ATR на момент формирования. Трём свечам нужны последовательные временные интервалы по 30 минут.

После формирования зоны стратегия ожидает не более `MaxWaitBars` следующих баров (по умолчанию 30). Вход происходит на пересечении сырым стохастиком %K уровня 20 сверху вниз: предыдущее значение не ниже 20, текущее ниже 20. `StochPeriod` по умолчанию равен 14; необходима история для обоих значений. По умолчанию касание зоны и сохранение её границ не требуются. Параметр `RequireEntryAboveFVGLower` принимает `0` (по умолчанию, фильтр выключен) или `1`: закрытие сигнальной свечи должно быть не ниже нижней границы выбранного FVG. Фактическое исполнение также разрешено только не ниже этой границы; гэп следующего открытия ниже неё отменяет вход. Равенство разрешено; касание зоны и отсутствие прежних пробоев не требуются. Для сравнения в гриде можно задать `"RequireEntryAboveFVGLower": [0, 1]`. Вход на баре формирования невозможен. При нескольких подходящих зонах выбирается последняя. Опциональный фильтр `HTFTrendEMA` требует, чтобы последняя завершённая дневная цена была выше EMA, рассчитанной по дневным закрытиям; период задаётся в дневных свечах, а значение 0 выключает фильтр.

Сигнал формируется на закрытии свечи и при отложенном входе действует только до открытия следующего M30-бара; отсутствующий слот отменяет сигнал. Вход на выходных запрещён. ATR Уайлдера рассчитывается по завершённым будним дневным свечам с периодом `ATRPeriod` (14 по умолчанию). Для величины FVG используется ATR на момент формирования, для расстояний стопа и цели — ATR на момент сигнала.

Стоп равен цене фактического исполнения минус `StopATR × ATR`, цель — цена исполнения плюс `TakeProfitATR × ATR`. Начальные значения — 1 и 2 соответственно, они не калиброваны. Значение `TakeProfitATR = 0` отключает ценовую цель. Позиция закрывается при касании стопа, достижении цели или, если `UseStochExit = 1` (по умолчанию), пересечении %K уровня 80 снизу вверх (предыдущее значение не выше 80, текущее выше). Значение `UseStochExit = 0` отключает только стохастический выход; стоп и тейк остаются активны. При одновременных событиях приоритет у стопа, затем у цели, затем у стохастика. Исполнение стопа и цели учитывает гэп открытия; выход по стохастику происходит на закрытии.

Гриды в `data/params/fvg_imbalance/` являются стартовыми и требуют отдельной калибровки и проверки вне периода подбора. Старые результаты для ретестовой стратегии неприменимы к новой механике.
