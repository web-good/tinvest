# hammer — молот в зоне перепроданности RSI(5) на 1h и 30m

Бэктест-стратегия, только лонг, часовые или получасовые свечи (`-strategy hammer -interval Hour1` или `-interval Minutes30`): другие таймфреймы cmd/backtest отклоняет. Правила и параметры на обоих таймфреймах одни и те же, считаются в свечах выбранного таймфрейма: на 30m EMA(200) охватывает 100 часов, а не 200, RSI(5) — 2.5 часа. Литералы тикеров общие для обоих таймфреймов. Сигнал — свечной молот, закрывшийся с RSI(5) ниже 30 над EMA(200) закрытий свечей на объёме выше 1.5 × среднего 20 свечей основной сессии. Вход — по открытию следующей свечи. Стоп — под минимумом молота с запасом в дневных ATR, цель — `TargetR` рисков над ценой покупки или выход по RSI выше 70. Код: `internal/service/trading_strategy/hammer/strategy/core`, привязка к бэктесту — `internal/service/backtest/hammer_registry.go`. Спека: `docs/superpowers/specs/2026-10-21-hammer-design.md`.

## Уровни

- **Дневной ATR** — Уайлдер `DailyATRPeriod` по завершённым будним дневкам (выходные дневки отброшены), замораживается в сигнале; задаёт только запас стопа под молотом.
- Дневок меньше `DailyATRPeriod + 1` или ATR не положителен — входов нет.

## Сигнал

Свеча `k` — сигнал, когда одновременно:

1. **Молот.** Диапазон свечи > 0, тело (любого цвета) больше нуля — доджи с open = close не молот; низ тела не ниже середины свечи, нижняя тень (от low до низа тела) не меньше двух тел, верхняя тень (от верха тела до high) допустима, но не длиннее одного тела (с 2026-10-22; до этого не ограничивалась). До 2026-10-22 тело требовалось в верхней трети и не больше трети диапазона, как в `isHammer` pdl_reclaim.
2. **Зона.** RSI(`RSIPeriod`) по закрытиям свечей на закрытии самой свечи `k` ниже `RSIZone`. RSI на предыдущих свечах роли не играет. RSI считается по всем свечам окна — утренней, основной, вечерней сессиям и выходным, без сброса на ночь.
3. **Тренд** (`TrendEMA > 0`, по умолчанию 200). Close свечи `k` строго выше EMA(`TrendEMA`) по закрытиям всех свечей окна. EMA засевается SMA первых `TrendEMA` закрытий; пока она не прогрета, входов нет. `TrendEMA = 0` выключает фильтр.
4. **Объём** (`VolumeMult > 0`, по умолчанию 1.5). Объём свечи `k` строго выше `VolumeMult` × среднего объёма `VolBars` (20) свечей основной сессии перед ней. Основная сессия — будние свечи, открывшиеся с 10:00 до 19:00 MSK (на 1h последняя — 18:00, на 30m — 18:30, в них закрывающий аукцион); утренняя, вечерняя сессии и выходные в среднее не входят, но сама свеча-молот может быть любой. Нет объёмов или стольких свечей основной сессии в окне — входов нет. `VolumeMult = 0` выключает фильтр.
5. **Календарь.** Свеча `k` — в будний день по Москве, и следующая свеча начинается в ту же дату: на последней вечерней свече сигнала нет, покупки на утреннем гэпе не бывает.

Покупка — по open свечи `k + 1`. После выхода новый сигнал снова покупает; позиция одна.

## Выходы

- **Стоп** — фиксированный уровень: low молота минус `StopBufferATR` (0.05) дневного ATR. От цены покупки не пересчитывается. Стоп не выше нуля или не ниже close молота — входа нет.
- **Цель** — `TargetR` (2) рисков над ценой покупки `f`: `f + TargetR · (f − стоп)`; `TargetR = 0` — цели нет. Покупка на гэпе на стопе или ниже — цели нет, стоп выходит сразу.

Сигнал на покупку несёт стоп и цель от close молота — для расчёта размера (`-risk-pct`): при гэпе на open покупки реальный риск немного отличается от расчётного; на 1h и 30m с покупкой в ту же дату гэп обычно мал. Порядок проверки на каждой свече позиции: low ≤ стопа — `SL`; high ≥ цели — `TP`; RSI(`RSIPeriod`) на закрытии выше `RSIExit` — `RSI` (`RSIExit = 0` — выключен). Стоп и цель не двигаются. Позиция переносится через ночь и выходные.

До 2026-10-22 были стоп в дневных ATR от цены покупки (`StopDailyATR`), цель — доля вчерашнего диапазона (`TargetRangeMult`) и вход под EMA (`BelowEMA` с выходом по RSI 50); удалены, остались в git-истории.

## Параметры

| Поле | По умолчанию | Смысл |
|---|---|---|
| `RSIPeriod` | 5 | длина RSI по закрытиям свечей |
| `RSIZone` | 30 | RSI свечи-молота ниже этого |
| `RSIExit` | 70 | выход, когда RSI на закрытии выше этого; 0 — выкл |
| `TrendEMA` | 200 | close молота строго выше EMA этого периода по закрытиям свечей; 0 — выкл |
| `VolumeMult` | 1.5 | объём молота строго выше этого × среднего `VolBars` свечей основной сессии; 0 — выкл |
| `VolBars` | 20 | сколько свечей основной сессии перед молотом в среднем объёма |
| `StopBufferATR` | 0.05 | запас стопа под low молота в дневных ATR |
| `TargetR` | 2 | цель в рисках от цены покупки; 0 — нет цели |
| `DailyATRPeriod` | 14 | период Уайлдера по будним дневкам (для запаса стопа) |

Литералы тикеров — `internal/service/trading_strategy/hammer/strategy/<ticker>/` (gazp, sber, nvtk); тикер без пакета работает на `core.DefaultParams`. Стартовая сетка — `data/params/hammer/grid_example.json`.

## Запуск

```
go run ./cmd/backtest -ticker GAZP -strategy hammer -interval Hour1 -months 12 -out ./reports/hammer/GAZP
go run ./cmd/backtest -ticker GAZP -strategy hammer -interval Hour1 -months 12 -risk-pct 1 -out ./reports/hammer/GAZP_risk
go run ./cmd/backtest -ticker GAZP -strategy hammer -interval Minutes30 -months 12 -out ./reports/hammer/GAZP_m30
```
