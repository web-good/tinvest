# hammer — молот в зоне перепроданности RSI(5) на 1h

Бэктест-стратегия, только лонг, только часовые свечи (`-strategy hammer -interval Hour1`): другие таймфреймы cmd/backtest отклоняет. Сигнал — свечной молот, закрывшийся с RSI(5) ниже 30 над EMA(200) часовых закрытий. Вход — по открытию следующей свечи. Стоп — в дневных ATR под ценой покупки, цель — доля вчерашнего дневного диапазона над ней или выход по RSI выше 70. Код: `internal/service/trading_strategy/hammer/strategy/core`, привязка к бэктесту — `internal/service/backtest/hammer_registry.go`. Спека: `docs/superpowers/specs/2026-10-21-hammer-design.md`.

## Уровни

- **Дневной ATR** — Уайлдер `DailyATRPeriod` по завершённым будним дневкам (выходные дневки отброшены), замораживается в сигнале.
- **Вчерашний диапазон** — high − low последней завершённой будней дневки (в понедельник это пятница), замораживается в сигнале.
- Дневок меньше `DailyATRPeriod + 1`, ATR или диапазон не положительны — входов нет.

## Сигнал

Свеча `k` — сигнал, когда одновременно:

1. **Молот.** Диапазон свечи > 0, тело (любого цвета) не больше трети диапазона и лежит в верхней трети. Отсюда нижний хвост не меньше 2/3 диапазона и не меньше двух тел. Определение то же, что у `isHammer` в pdl_reclaim.
2. **Зона.** RSI(`RSIPeriod`) по закрытиям часовых свечей на закрытии самой свечи `k` ниже `RSIZone`. RSI на предыдущих свечах роли не играет. RSI считается по всем часовым свечам окна — утренней, основной, вечерней сессиям и выходным, без сброса на ночь.
3. **Тренд** (`TrendEMA > 0`, по умолчанию 200). Close свечи `k` строго выше EMA(`TrendEMA`) по закрытиям всех часовых свечей окна. EMA засевается SMA первых `TrendEMA` закрытий; пока она не прогрета, входов нет. `TrendEMA = 0` выключает фильтр.
4. **Календарь.** Свеча `k` — в будний день по Москве, и следующая свеча начинается в ту же дату: на последней вечерней свече сигнала нет, покупки на утреннем гэпе не бывает.

Покупка — по open свечи `k + 1`. После выхода новый сигнал снова покупает; позиция одна.

## Выходы

Стоп и цель пересчитываются от цены покупки `f`; расстояния заморожены в сигнале:

- **стоп** = `f − StopDailyATR · ATR`;
- **цель** = `f + TargetRangeMult · вчерашний диапазон`; `TargetRangeMult = 0` — цели нет.

Сигнал на покупку несёт те же уровни от close сигнальной свечи — для расчёта размера (`-risk-pct`). Размер поэтому считается от стопа сигнала: при гэпе на open покупки реальный риск отличается от расчётного, а при open на стопе сигнала или ниже размер откатывается к `-fraction`; на 1h с покупкой в ту же дату гэп обычно мал. Порядок проверки на каждой свече позиции: low ≤ стопа — `SL`; high ≥ цели — `TP`; RSI(`RSIPeriod`) на закрытии выше `RSIExit` — `RSI` (`RSIExit = 0` — выключен). Стоп и цель не двигаются. Позиция переносится через ночь и выходные.

## Параметры

| Поле | По умолчанию | Смысл |
|---|---|---|
| `RSIPeriod` | 5 | длина RSI по часовым закрытиям |
| `RSIZone` | 30 | RSI свечи-молота ниже этого |
| `RSIExit` | 70 | выход, когда RSI на закрытии выше этого; 0 — выкл |
| `TrendEMA` | 200 | close молота строго выше EMA этого периода по часовым закрытиям; 0 — выкл |
| `StopDailyATR` | 0.5 | стоп под ценой покупки в дневных ATR; ≤ 0 — входов нет |
| `TargetRangeMult` | 0.5 | цель — доля вчерашнего диапазона над ценой покупки; 0 — нет цели |
| `DailyATRPeriod` | 14 | период Уайлдера по будним дневкам |

Литералы тикеров — `internal/service/trading_strategy/hammer/strategy/<ticker>/` (gazp, sber, nvtk); тикер без пакета работает на `core.DefaultParams`. Стартовая сетка — `data/params/hammer/grid_example.json`.

## Запуск

```
go run ./cmd/backtest -ticker GAZP -strategy hammer -interval Hour1 -months 12 -out ./reports/hammer/GAZP
go run ./cmd/backtest -ticker GAZP -strategy hammer -interval Hour1 -months 12 -risk-pct 1 -out ./reports/hammer/GAZP_risk
```
