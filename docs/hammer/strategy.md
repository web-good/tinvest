# hammer — молот в зоне перепроданности RSI(5) на 1h и 30m

Бэктест-стратегия, только лонг, часовые или получасовые свечи (`-strategy hammer -interval Hour1` или `-interval Minutes30`): другие таймфреймы cmd/backtest отклоняет. Правила и параметры на обоих таймфреймах одни и те же, считаются в свечах выбранного таймфрейма: на 30m EMA(200) охватывает 100 часов, а не 200, RSI(5) — 2.5 часа. Литералы тикеров общие для обоих таймфреймов. Сигнал — свечной молот, закрывшийся с RSI(5) ниже 30 над EMA(200) закрытий свечей на объёме выше 1.5 × среднего 20 свечей основной сессии. Вход — по открытию следующей свечи. Стоп — в дневных ATR под ценой покупки, цель — доля вчерашнего дневного диапазона над ней или выход по RSI выше 70. Код: `internal/service/trading_strategy/hammer/strategy/core`, привязка к бэктесту — `internal/service/backtest/hammer_registry.go`. Спека: `docs/superpowers/specs/2026-10-21-hammer-design.md`.

## Уровни

- **Дневной ATR** — Уайлдер `DailyATRPeriod` по завершённым будним дневкам (выходные дневки отброшены), замораживается в сигнале.
- **Вчерашний диапазон** — high − low последней завершённой будней дневки (в понедельник это пятница), замораживается в сигнале.
- Дневок меньше `DailyATRPeriod + 1`, ATR или диапазон не положительны — входов нет.

## Сигнал

Свеча `k` — сигнал, когда одновременно:

1. **Молот.** Диапазон свечи > 0, тело (любого цвета) больше нуля — доджи с open = close не молот; низ тела не ниже середины свечи, нижняя тень (от low до низа тела) не меньше двух тел. Длина верхней тени не ограничена. До 2026-10-22 тело требовалось в верхней трети и не больше трети диапазона, как в `isHammer` pdl_reclaim.
2. **Зона.** RSI(`RSIPeriod`) по закрытиям свечей на закрытии самой свечи `k` ниже `RSIZone`. RSI на предыдущих свечах роли не играет. RSI считается по всем свечам окна — утренней, основной, вечерней сессиям и выходным, без сброса на ночь.
3. **Тренд** (`TrendEMA > 0`, по умолчанию 200). Close свечи `k` строго выше EMA(`TrendEMA`) по закрытиям всех свечей окна. EMA засевается SMA первых `TrendEMA` закрытий; пока она не прогрета, входов нет. `TrendEMA = 0` выключает фильтр.
4. **Объём** (`VolumeMult > 0`, по умолчанию 1.5). Объём свечи `k` строго выше `VolumeMult` × среднего объёма `VolBars` (20) свечей основной сессии перед ней. Основная сессия — будние свечи, открывшиеся с 10:00 до 19:00 MSK (на 1h последняя — 18:00, на 30m — 18:30, в них закрывающий аукцион); утренняя, вечерняя сессии и выходные в среднее не входят, но сама свеча-молот может быть любой. Нет объёмов или стольких свечей основной сессии в окне — входов нет. `VolumeMult = 0` выключает фильтр.
5. **Календарь.** Свеча `k` — в будний день по Москве, и следующая свеча начинается в ту же дату: на последней вечерней свече сигнала нет, покупки на утреннем гэпе не бывает.

**Вход под EMA** (`BelowEMA = 1`, по умолчанию выключен; нужен `TrendEMA > 0`). Молот, закрывшийся строго под прогретой EMA, тоже покупает, но по своему RSI: RSI(`BelowRSIPeriod`, 6) на закрытии молота ниже `BelowRSIZone` (30) вместо пункта 2. Объём и календарь — те же. Close ровно на EMA не покупает ни в одном режиме.

Покупка — по open свечи `k + 1`. После выхода новый сигнал снова покупает; позиция одна.

## Выходы

Без `StopBelowHammer` стоп и цель пересчитываются от цены покупки `f`; расстояния заморожены в сигнале:

- **стоп** = `f − StopDailyATR · ATR`;
- **цель** = `f + TargetRangeMult · вчерашний диапазон`; `TargetRangeMult = 0` — цели нет.

Сигнал на покупку несёт те же уровни от close сигнальной свечи — для расчёта размера (`-risk-pct`). Размер поэтому считается от стопа сигнала: при гэпе на open покупки реальный риск отличается от расчётного, а при open на стопе сигнала или ниже размер откатывается к `-fraction`; на 1h и 30m с покупкой в ту же дату гэп обычно мал. Порядок проверки на каждой свече позиции: low ≤ стопа — `SL`; high ≥ цели — `TP`; RSI(`RSIPeriod`) на закрытии выше `RSIExit` — `RSI` (`RSIExit = 0` — выключен). Стоп и цель не двигаются. Позиция переносится через ночь и выходные.

**Стоп под молотом** (`StopBelowHammer = 1`, по умолчанию выключен). Стоп — фиксированный уровень: low молота минус `StopBufferATR` (0.05) дневного ATR; от цены покупки он не пересчитывается, `StopDailyATR` не используется. Цель — `TargetR` (2) рисков над ценой покупки: `f + TargetR · (f − стоп)`; `TargetR = 0` — цели нет, `TargetRangeMult` не используется. Покупка на гэпе на стопе или ниже — цели нет, стоп выходит сразу. Вход под EMA и здесь остаётся без цели.

Позиция, купленная под EMA, выходит иначе: цели нет, выход по RSI 70 не действует; выходы — стоп (`SL`, тот же `StopDailyATR`) и пересечение RSI(`BelowRSIPeriod`) уровня `BelowRSIExit` (50) снизу вверх на закрытии свечи — предыдущая ≤ уровня, текущая выше (`RSI50`, по close; `BelowRSIExit = 0` — только стоп). Режим позиция узнаёт по сигналу: только сигнал под EMA несёт EMA в `Level`, движок отдаёт её в `Position.EntryLevel`; уровень больше нуля — режим под EMA.

## Параметры

| Поле | По умолчанию | Смысл |
|---|---|---|
| `RSIPeriod` | 5 | длина RSI по закрытиям свечей |
| `RSIZone` | 30 | RSI свечи-молота ниже этого |
| `RSIExit` | 70 | выход, когда RSI на закрытии выше этого; 0 — выкл |
| `TrendEMA` | 200 | close молота строго выше EMA этого периода по закрытиям свечей; 0 — выкл |
| `VolumeMult` | 1.5 | объём молота строго выше этого × среднего `VolBars` свечей основной сессии; 0 — выкл |
| `VolBars` | 20 | сколько свечей основной сессии перед молотом в среднем объёма |
| `BelowEMA` | 0 | 1 — покупать и молот под EMA по своим правилам |
| `BelowRSIPeriod` | 6 | длина RSI входа и выхода под EMA |
| `BelowRSIZone` | 30 | RSI молота под EMA ниже этого |
| `BelowRSIExit` | 50 | выход под EMA на пересечении этого уровня RSI снизу вверх; 0 — выкл |
| `StopDailyATR` | 0.5 | стоп под ценой покупки в дневных ATR; ≤ 0 — входов нет |
| `StopBelowHammer` | 0 | 1 — стоп под low молота, цель в R |
| `StopBufferATR` | 0.05 | запас стопа под low молота в дневных ATR |
| `TargetR` | 2 | цель в рисках от цены покупки при стопе под молотом; 0 — нет цели |
| `TargetRangeMult` | 0.5 | цель — доля вчерашнего диапазона над ценой покупки; 0 — нет цели |
| `DailyATRPeriod` | 14 | период Уайлдера по будним дневкам |

Литералы тикеров — `internal/service/trading_strategy/hammer/strategy/<ticker>/` (gazp, sber, nvtk); тикер без пакета работает на `core.DefaultParams`. Стартовая сетка — `data/params/hammer/grid_example.json`.

```
go run ./cmd/backtest -ticker GAZP -strategy hammer -interval Hour1 -months 12 -out ./reports/hammer/GAZP
```
