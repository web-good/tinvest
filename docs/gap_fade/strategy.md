# gap_fade — фейд утреннего гэпа вниз

Лонговая внутридневная стратегия на 30m. Ядро: `internal/service/trading_strategy/gap_fade/strategy/core`.
Спека: `docs/superpowers/specs/2026-10-02-gap-fade-design.md`.

## Как торгует

Идея: утренний гэп вниз часто оказывается паникой, и за день цена частично возвращается к
вчерашнему закрытию. Стратегия покупает такую просадку утром и продаёт в тот же день.

Стратегия существует только в бэктесте и реальных заявок не ставит. Каждый тикер она проверяет
отдельно, по одному правилу, и держит по нему не больше одной позиции в день. Какие тикеры она
видит, зависит от запуска: `cmd/backtest` — один тикер из `-ticker`, `cmd/gapwf` — вселенная
`GAP_FADE_TICKERS`, которую отбирает скринер `cmd/gapscreen` (`screener.md`). Параметры для всех
тикеров общие (см. «Почему без калибровки по тикерам»).

По шагам, только в будни:

1. **Сравнивает открытие со вчерашним закрытием.** Сделка возможна, только если акция открылась
   заметно ниже вчерашнего закрытия — минимум на `GapATR` дневных ATR (ATR — средний дневной
   размах цены за 14 дней). Гэп глубже `MaxGapATR` пропускается: это уже событие (плохая новость,
   дивидендная отсечка), а не утренняя паника.
2. **Покупает.** Сигнал — close первого бара дня (06:30–07:00), если цена всё ещё ниже вчерашнего
   закрытия. Покупка — по open следующего бара в 07:00, то есть по первой цене, которую реально
   можно получить после аукциона открытия.
3. **Сразу ставит цель и стоп.** Цель — возврат вверх на долю гэпа `TargetFill` (0.5 — половина,
   1.0 — весь гэп). Стоп — на `StopDailyATR` дневных ATR ниже входа.
4. **Ждёт до вечера.** На каждом баре по порядку: дошли до стопа — продажа с убытком; дошли до
   цели — продажа с прибылью; ни то ни другое до 18:30 — продажа по рынку. Через ночь позиция
   никогда не переносится.

Пример с круглыми числами:

- вчера акция закрылась на 100 ₽, дневной ATR — 4 ₽;
- сегодня она открылась на 97 ₽: гэп −3 ₽, то есть 0.75 ATR, — условие выполнено;
- покупка в 07:00 по 97.20 ₽;
- цель на половину оставшегося гэпа — около 98.60 ₽, стоп на 1 ATR ниже входа — 93.20 ₽;
- к обеду цена дошла до 98.60 ₽ — продажа, +1.4%.

Чаще всего сделка закрывается по цели в первые часы. Сигналы редкие: гэп вниз нужного размера
бывает у отдельной бумаги в среднем раз в несколько месяцев.

### Почему без калибровки по тикерам

На один тикер приходятся единицы сделок за несколько лет. Подбор параметров по такой выборке —
подгонка под шум, а не калибровка. Поэтому стратегия проверяется как одно правило на всей
вселенной: параметры общие, сделки всех тикеров складываются в один пул (`cmd/gapwf`).
Пакетов по тикерам нет, общие параметры — `internal/service/backtest/gap_fade_registry.go`.

## Механика

- **День** — календарная дата бара в MSK. Первый бар дня — бар, чья дата отличается от даты предыдущего.
- **prevClose** — close бара перед первым баром дня (последняя сделка до сессии, сессии выходного дня включительно).
- **Вход** (только будни, бар номер `EntryBar` дня, начало бара раньше EOD):
  гэп `(open первого бара − prevClose) / дневной ATR` не больше `−GapATR` и не меньше `−MaxGapATR`
  (`MaxGapATR = 0` — без ограничения), close бара входа ниже prevClose. Сигнал — на close этого бара; исполнение в бэктесте (`-strategy gap_fade`
  и `cmd/gapwf`) — по open следующего бара (`Config.EntryAtNextOpen`): первый бар дня часто один
  аукционный принт, и купить по цене, от которой считан сигнал, нельзя. Бар исполнения уже
  проверяется на стоп и цель.
- **Уровни** считаются от close сигнального бара и замораживаются: цель `close + TargetFill · (prevClose − close)`, стоп `close − StopDailyATR · ATR`.
- **Выходы** по приоритету: `SL` (исполнение по `min(стоп, open)`), `TP` (по `max(цель, open)`),
  `EOD` — бар с началом не раньше `EODHour:EODMinute` MSK, первый бар новой даты или любой бар
  следующей даты (по close); без времён баров позиция закрывается сразу. Позиция никогда не
  переносится через ночь.
- **Дневной ATR** — Уайлдер(`DailyATRPeriod`) по завершённым будним дневкам.
- Ядру нужны цены открытия (`MarketData.Opens`); без них входа нет.

## Параметры

| Поле | Дефолт | Смысл |
|---|---|---|
| `GapATR` | 0.5 | минимальная глубина гэпа в дневных ATR |
| `MaxGapATR` | 3.0 | гэп глубже — событие, не входим; 0 — без ограничения |
| `EntryBar` | 0 | номер бара дня для входа (0 — первый) |
| `TargetFill` | 1.0 | доля оставшегося гэпа для цели |
| `StopDailyATR` | 0.5 | стоп в дневных ATR |
| `DailyATRPeriod` | 14 | период дневного ATR |
| `EODHour`, `EODMinute` | 18, 30 | время принудительного выхода, MSK |

## Запуск

- Один тикер: `go run ./cmd/backtest -ticker GAZP -strategy gap_fade -interval Minutes30 -months 24`.
  Фильтра дивидендных отсечек здесь нет: гэп отсечки выглядит как сигнал.
- Валидация на вселенной: `go run ./cmd/gapwf` — общие параметры на все тикеры, сетка
  `data/params/gap_fade/grid.json`, walk-forward 36/12/3 по пулу сделок, pooled PF по процентной
  доходности сделок. Вселенная — `-tickers` через запятую, по умолчанию `GAP_FADE_TICKERS` из
  `-env-file env/prod.env` (строку даёт `cmd/gapscreen`; без неё команда падает с подсказкой).
  Сделки дня отсечки выброшены: дивиденды берутся из T-Invest
  `GetDividends`, день отсечки — дата первого торгового бара после `last_buy_date`.
  Команда печатает вердикт гейта из шести условий: pooled OOS PF ≥ 1.5; за последние 12 месяцев
  ≥ 1.2; прибыльны ≥ 60% тикеров со сделками; при 0.2% на сторону ≥ 1.0; сделок в pooled OOS
  ≥ `-min-trades`; сделок за последние 12 месяцев ≥ 20. Отчёт — `reports/gap_fade/gapwf_<время>.md`.
  Таблица дней отсечки в отчёте показывает по каждому тикеру число различных дней отсечки, в которые сделки были выброшены (не число сделок: оно различается по комбинациям сетки).
- Live нет. Запас стратегии по издержкам небольшой, а реальная стоимость входа на утреннем
  открытии (спред и проскальзывание в тонком стакане) бэктестом не меряется. Без такого замера
  live не делается.
