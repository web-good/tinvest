Документация по реализации в `internal/service/trading_strategy/scalping/`.

## Что это

Скальпинг-сервис гоняет набор **по-акционных** стратегий на часовом (H1) таймфрейме.
Каждая стратегия — это отдельное торговое правило для одной бумаги, реализующее общий
контракт `strategy.Strategy`. Сейчас в реестре одна стратегия — адаптивная стратегия
для RUSAL (тикер `RUAL`).

Ключевая идея архитектуры: **всё I/O — в раннере, вся логика — в чистой функции.**
Раннер (`trade.go`) грузит свечи и портфель через gRPC, отправляет алерты в Telegram;
стратегия лишь считает индикаторы из переданного окна свечей и возвращает `Signal`.
Решение (`Decide`) детерминировано и не делает никаких побочных эффектов — поэтому его
легко покрыть табличными тестами.

## Контракт стратегии

`strategy.Strategy` (`internal/service/trading_strategy/scalping/strategy/strategy.go`):

```go
type Strategy interface {
    Ticker() string              // тикер бумаги, например "RUAL"
    Lookback() int               // сколько свечей нужно для прогрева индикаторов
    Decide(md MarketData) model.Signal
}
```

- `MarketData` — снимок рынка по одной бумаге: срезы `Highs/Lows/Closes/Volumes`
  (oldest-first, выровнены по одним свечам), `Price` (последний close) и `Position`
  (`nil`, когда позиции нет).
- `model.Signal` — готовый торговый алерт: `Kind` (`None`/`Buy`/`Sell`), `Price`,
  `TakeProfit`, `StopLoss`, `RSI`, `Reason` (`"SL"`/`"TRAIL"`/`"TP"` для продаж).

## Как RUSAL подключается в раннер

| Слой | Файл | Ответственность |
|---|---|---|
| Реестр | `scalping/registry.go` | `defaultStrategies()` — фиксированный список стратегий (`rusal.New()`) |
| Раннер | `scalping/trade.go` | загрузка свечей/портфеля, цикл по стратегиям, отправка в Telegram |
| Стратегия | `scalping/strategy/rusal/rusal.go` | `Decide()` — индикаторы + чистое ядро `decide()` |
| Индикаторы | `pkg/indicators/` | `ADX`, `Donchian`, `ATR`, `RSISeries` (чистые, без I/O) |

Цикл раннера (`trade.go:47`): для каждой стратегии берёт `Ticker()`, грузит
`Lookback()` свечей, строит `MarketData`, подставляет открытую позицию из портфеля,
вызывает `Decide()` и собирает непустые сигналы в одно Telegram-сообщение.

## Важное предупреждение о калибровке

Дефолтные параметры (`DefaultParams()`) — это **стандартные, ещё не откалиброванные**
на реальной истории RUAL значения. Их выбор основан на общепринятых практиках
технического анализа, а не на бэктесте конкретной бумаги. Все «ручки» вынесены в
`Params` — калибровка не трогает логику, только числа. Подбирать их следует на
исторических свечах через инструмент бэктеста (`cmd/backtest`): см.
[../backtest/README.md](../backtest/README.md) и [settings.md](settings.md).
