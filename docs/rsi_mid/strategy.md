# RSI mid (лонг, многодневный, любой таймфрейм)

Код: `internal/service/trading_strategy/rsi_mid/strategy/core/`
Реестр бэктеста: `internal/service/backtest/rsi_mid_registry.go`
Грид калибровки: `data/params/rsi_mid/grid.json`
Спека: `docs/superpowers/specs/2026-10-01-rsi-mid-design.md`

## 1. Идея

Покупка возобновления движения в тренде: RSI пересекает среднюю линию 50 снизу вверх, пока цена
закрытия выше трендовой EMA. Выход — стоп в дневных ATR, замороженный на входе; крест RSI через
верхнюю полосу; или серия баров с RSI ниже 50 после входа (движение не продолжилось). Целей, трейла и
закрытия в конце дня нет: позиция переносится через ночь и выходные.

Роль — пара к `rsi_pullback` на общем счёте. Pullback покупает дно глубокого отката, rsi_mid —
продолжение после мелкого отката, до которого pullback не доходит. На одном и том же отскоке
стратегии коррелируют (rsi_mid покупает ту же дугу позже), поэтому польза пары меряется прогоном
обеих стратегий с занятостью тикера и приоритетом pullback, а не предполагается.

## 2. Параметры

| Поле | Единица | Дефолт | В гриде |
|---|---|---|---|
| `RSIPeriod` | баров | 14 | entry: 5, 7, 9, 14, 21 |
| `EMAPeriod` | баров | 100 | trend: 20, 50, 100, 150, 200 |
| `RSIUpper` | пункты RSI | 70 | exit: 60, 65, 70, 75, 80, 85 |
| `BelowMidBars` | баров после бара входа | 2 | exit: 1, 2, 3, 4, 6 |
| `StopDailyATR` | множитель дневного ATR | 0.5 | risk: 0.2, 0.3, 0.5, 0.7, 1.0 |
| `DailyATRPeriod` | будних дневок | 14 | нет (фиксирован) |

Средняя линия 50 — константа. `EMAPeriod ≤ 0` или `RSIPeriod ≤ 0` — нет сигнала. `BelowMidBars = 0`
выключает выход `MID`, `StopDailyATR = 0` — стоп; ни то, ни другое в сетку не входит намеренно
(для `BelowMidBars` нижняя точка оси — 1).

## 3. Вход

Позиции нет; проверки на закрытии последнего бара `i`, первый несработавший гейт отклоняет вход:

1. **Будний день** по MSK. Нулевое или невыровненное время бара гейт пропускает.
2. **Крест 50 вверх:** `i-1 ≥ RSIPeriod && rsi[i-1] ≤ 50 && rsi[i] > 50`. Прогрев отсекается по
   индексу. Событие, не состояние: пока RSI выше 50, повторного входа нет.
3. **Тренд:** `EMA[i] > 0 && close[i] > EMA[i]`; равенство — не тренд.
4. **Дневной ATR > 0** — ATR Уайлдера по завершённым будним дневкам.
5. **Стоп выше нуля:** `close − StopDailyATR × ATR > 0` при включённом стопе.

Покупка по close.

Особенность индикатора: на отрезке без единого падающего бара `indicators.RSISeries` читает ровно 50
(средний убыток равен нулю). Первый же падающий бар после такого отрезка даёт крошечный, но
положительный средний убыток при большом среднем росте, и RSI прыгает с 50 примерно до 79 — формально
это крест 50 вверх, то есть ложный вход на первом падающем баре. На реальных данных MOEX окна в 120+ баров
без единого падающего бара не бывает, поэтому стратегия от этого не защищается; тестовая фикстура
(`crossCloses`) по этой причине содержит контрдвижение на каждом четвёртом разгонном баре.

## 4. Выход

Приоритет `SL → RSI → MID`:

1. **`SL`** — `low ≤ вход − StopDailyATR × EntryATR`, ATR заморожен на входе. Исполнение
   `min(стоп, open)`. Без `EntryATR` стопа нет.
2. **`RSI`** — RSI пересёк `RSIUpper` снизу вверх на текущем баре; по close. Нужен именно крест:
   если RSI уже на баре входа выше `RSIUpper`, этот выход ждёт ухода под полосу и нового креста.
3. **`MID`** — последние `BelowMidBars` баров подряд, все строго после бара входа, с RSI < 50; по
   close. Бар с RSI ≥ 50 обнуляет счёт. Бар входа — последний бар, открывшийся не позже
   `Position.EntryTime`. Если бар входа вышел из окна свечей, счёт идёт по всему окну (на 5m окно
   по умолчанию — 220 баров, меньше двух дней). Без `EntryTime`/`Times` выход молчит.

На общем баре стоп побеждает. Календарного гейта у выходов нет.

## 5. Запуск

Таймфрейм любой: все периоды — в барах.

```
go run ./cmd/backtest -ticker <TICKER> -strategy rsi_mid -interval Minutes30 -months 36
go run ./cmd/backtest -ticker <TICKER> -strategy rsi_mid -interval Minutes30 \
  -calibrate data/params/rsi_mid/grid.json -out ./reports/<TICKER> -months 36 \
  -min-trades 20 -test-months 6 -metric profit_factor
```

Калибровка фазовая (entry → trend → exit → risk, keepTop 5, 205 комбинаций). Судить по pooled OOS
profit factor walk-forward (планка ≥ 1.5), не по лучшей in-sample точке.

## 6. Литералы и таймфреймы

Литерал тикера привязан к таймфрейму калибровки. Пакет тикера
`internal/service/trading_strategy/rsi_mid/strategy/<ticker>/` держит `Literals()` —
`map[enum.Interval]core.Params` — и регистрируется в `rsiMidRegistry`. Реестр выбирает литерал по
паре (тикер, `-interval`); если пары нет — `core.DefaultParams()`, литерал другого таймфрейма не
подставляется никогда. У тикера с литералом поля, которых нет в гриде, берутся из литерала.

Live-раннера нет. Ядро совместимо с гостевым режимом раннера счёта rsi_pullback (тот же
`model.Signal`, якорь бара входа — `Position.EntryTime`).
