# Формирование локальной сетки

Этот этап зависит от результатов предыдущих прогонов: фиксированной готовой сетки нет.

1. Скопируй полный выбранный набор в grid: каждое из девяти полей сначала представлено одноэлементным массивом.
2. Для `StopATR`, `TakeProfitATR`, `MinGapATR` возьми выбранное значение и ближайшие уже исследованные значения с каждой стороны. Используй фактические сетки запуска, включая добавленные значения тикера.
3. Для `RequireEntryAboveFVGLower` задай `[0, 1]`. Остальные поля оставь фиксированными, включая выбранную ветку `UseStochExit`.
4. Получится не более 54 совместных сочетаний. На краю диапазона допустим один заранее записанный ограниченный шаг расширения; не допускай `StopATR <= 0` или отрицательных `MinGapATR`/`TakeProfitATR`.
5. Для проверки чувствительности создай отдельные сетки из полного финалиста, меняя только одно поле: соседние исследованные `StochPeriod`, альтернативный `HTFTrendEMA`, затем `MaxWaitBars: [15, 30, 45]`. Не объединяй эти проверки в одно декартово произведение.

Если чувствительность выявила лучший допустимый набор, выполни вокруг него только один повтор совместной локальной сетки. Правила годового допуска и остановки находятся в `../SKILL.md`.
