# T M30 FVG imbalance calibration plan

- Snapshot/run clock: 2026-11-11 Europe/Moscow. Available cached M30: 2022-08-29 09:30 MSK through 2026-11-10 23:30 MSK (45,264 bars); daily: 2022-10-28 through 2026-11-09 (1,134 bars). Candle provider is Tinkoff Invest API with repository cache `data/candles`; preserve candle files as the reproducible snapshot and record actual report boundaries. Only completed bars are used by the engine.
- Selection window: 2023-11-11 through 2025-11-11 (24 months), split into `[2023-11-11, 2024-11-11)` and `[2024-11-11, 2025-11-11)`. Reserved final check: `[2025-11-11, 2026-11-11)`; do not inspect candidate results there until one complete candidate is frozen. Use the same loaded candle snapshot and boundaries for all comparisons. If exact report boundaries differ, record them and count closed trades from the full trades CSV by entry date.
- Warm-up: engine-provided lead-in; daily history begins approximately one year before range start for daily ATR/EMA. ATRPeriod=14, requiring 28 daily bars per strategy implementation. M30 and daily candles are completed only. Execution is next M30 open; gaps, stop/target ordering and fees follow the engine unchanged.
- Capital/execution: `-cash 100000 -fraction 1 -risk-pct 0 -commission 0.0005`, default lot from instrument. Position sizing is fixed fraction of available cash, no leverage setting changed.
- Calibration baseline: skill `referens/baseline.json`; original ticker literal separately saved as `original.json` and run as control. Stage 1 grid includes the template values plus original literal values: MinGapATR `[0,0.1,0.25,0.35,0.5,0.8]`, RequireEntryAboveFVGLower `[0,1]`, HTFTrendEMA `[0,50,100,200]`, StochPeriod `[9,12,14,21]`; base exits and MaxWaitBars fixed to baseline. This is 192 combinations plus baseline control.
- Primary metric: expectancy (net trade PnL per closed trade); fixed quality constraints on every selected run: positive Net PnL after commission, PF > 1, MaxDrawdownPct <= 0.10. Stage transfer requires >=20 closed trades over 24 months and >=10 entries by closed trades in each of the two calendar-aligned 12-month blocks. Open positions do not count. Final window requires >=10 closed trades and the same quality constraints.
- Stage 2: for each selected Stage 1 seed, separate full 16-combination StopATR x TakeProfitATR grids for UseStochExit 1 and 0, all other fields explicit. Stage 3 follows `referens/stage-3-refinement.md`, capped at one 54-combination refinement and single-field sensitivity grids. Use `-combos 0` throughout.
- Search budget: at most 1,000 parameter evaluations total (control runs excluded); stage 1 192, stage 2 at most 4 seeds x 2 x 16 = 128, leaving up to 680 for stage 3 and required fixed-parameter year/block checks. If the budget prevents exhaustive follow-up, report search incompleteness and do not claim no qualifying set exists.
- Stage 1 and Stage 2 training data only. Compare branch candidates by expectancy, annual-block outcomes, drawdown, trade count, and neighboring grid values; if branch expectancy difference is <=5% of the larger absolute value, refine both branches. Freeze one complete nine-field candidate before running either reserved-year comparison. Final year runs only original literal and frozen candidate once each.
