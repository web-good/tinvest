# NVTK FVG imbalance calibration plan (2026-11-12)

## Locked protocol
- Training: intended [2023-11-12, 2025-11-12) (24 months), split [2023-11-12, 2024-11-12) and [2024-11-12, 2025-11-12). Reserved final test: [2025-11-12, 2026-11-12); candidate must be frozen before opening its results.
- Source: Tinkoff Invest API using cmd/backtest and repository data/candles cache; use completed M30, daily and H4 candles only. Before the final refresh the M30 cache ended 2026-10-21 and daily cache 2026-10-26. Training reports ran 2023-11-12 16:11–2025-11-12 16:11 on 23,857 completed M30 candles, with 814 daily and 4,169 H4 candles available including lead-in. Before the final run the cache was refreshed; final reports cover 2025-11-12 16:17–2026-11-12 16:17. The original run reused the refreshed cache.
- Warmup: engine daily lead-in approximately one year before window start; ATRPeriod=14 (28 completed daily bars required), EMA uses completed daily closes. Strategy only enters on completed M30 close and fills at next M30 open. Stops/targets and fees follow engine unchanged.
- Execution: -cash 100000 -fraction 1 -risk-pct 0 -commission 0.0005; default instrument lot; fixed-fraction sizing; same candle snapshot and costs throughout.
- Primary metric: expectancy. Fixed admission: positive Net PnL after commissions, PF > 1, MaxDrawdownPct <= 0.10 (fraction of running equity peak; report percent is this value ×100). All stages/branches require >=20 closed trades overall and >=10 closed-trade entries in each of the two training blocks. Final year requires >=10 closed trades and same quality constraints. Open positions do not count.
- Baseline: skill referens/baseline.json copied here. Original ticker settings separately saved in original.json (package currently returns core defaults). Stage 1: 350 combinations, using reference axes; original entry values are represented. Fixed baseline exit values and MaxWaitBars=30. Keep all results with -combos 0 and independently run original control.
- Stage 2: independent StopATR × TakeProfitATR grids for each admitted Stage-1 input and each UseStochExit branch, all nine fields explicit. Stage 3 uses reference local refinement rules and separate single-axis sensitivities; maximum 1,000 total parameter evaluations. Fixed-parameter year/block runs count toward the budget. The precommitted ceiling was 1,000; grid runs, fixed-parameter qualification replays, sensitivities and two final runs together stayed below that ceiling.
- Final: only after one full candidate is locked, run that candidate and original settings once each on the reserved 12 months with clean position and engine warmup. Update literal only if complete window, trade minimum, and quality rules all pass.
