# План SMLT, 2026-11-12

Подбор: [2023-11-12, 2025-11-12), два последовательных года; резерв [2025-11-12, 2026-11-12). Точные границы зависят от времени CLI и проверяются по свечам. Финальный год не просматривается до фиксации кандидата. Источник: T-Invest API и локальный кэш завершённых свечей M30 и Day1; год дневного прогрева до начала подбора. ATR=14, EMA прогревается по доступным завершённым дневным свечам. Исполнение на следующем открытии, капитал 100000 RUB, комиссия 0.0005 на оборот, fraction=1, risk-pct=0, лот инструмента из API.

Метрика expectancy; допуск: >=20 закрытых сделок за подбор и >=10 в каждом году по датам входа, Net PnL > 0, PF > 1, MaxDrawdownPct <= 0.10. В отчёте сетки Max DD — абсолютная сумма, не процент; процент проверяется полным прогоном. Финальный год: >=10 и те же ограничения качества.

Бюджет: полный этап 1 (350 сочетаний общей сетки; исходные входные значения уже присутствуют) и контроль исходного набора; до четырёх устойчивых допустимых входов; две полные сетки выхода на каждый, локальное уточнение и проверки чувствительности по навыку, затем один кандидат и один контроль на резерве. Если недоступны API или необходимая история, сохранить фактические результаты и не менять литерал. Граница нового бара между запусками требует подтверждения одинакового набора свечей.
